- 一键导出真实 `.docx`：A3横向、双栏、数字引用，人大通用参考值为红色
- A3横向双栏的《结构初步设计说明》网页版

## 启动

双击工作目录根部的 `启动Demo.cmd`，或在本目录执行：

```powershell
pnpm dev
```

浏览器打开终端提示的本地地址，默认是 `http://127.0.0.1:5173`。

统一技术措施复刻页可直接打开：

```text
http://127.0.0.1:5173/workbuddy-unified-measures.html
```

该页面复制自：

```text
E:\11-工作\001-workbuddy space\001-workbuddy space\103-结构扩初说明\结构计算统一措施_江南.html
```

页面结构、样式、文案、参数数据和交互直接复制自上述文件；可见界面不改。原网页的 HTML `.doc` 导出已替换为真正的 OOXML `.docx` 生成器，避免 Word 对网页 CSS 的近似解释造成版式漂移。

Word 输出按孟博版式锁定：A3 横向（420×297mm）、等宽双栏、栏间距 425 twips、上下页边距 1800 twips、左右页边距 1440 twips、宋体 / Times New Roman、正文小四号与 1.5 倍行距；文档从“1 总则”开始，不增加封面、页眉或页脚。网页中的删除按钮、编辑工具和操作列不会进入 Word。

生产构建：

```powershell
pnpm build
pnpm preview
```

重新解析规范 Markdown 或生成固定参数的 Word 样例：

```powershell
pnpm generate:regulations
pnpm generate:word-sample
```

## 操作

- 点击关键参数行查看来源、陈述类型和校核说明。
- “人为确认”页默认显示需要人工确认的字段；保存结果仅进入浏览器本地覆盖层，不回写 04/05 原始资料。完成后用“导出确认记录”归档。
- 统一参数可按八个专业分组浏览，并支持顶部搜索；本项目值使用正常深色，人大通用参考值使用红色。
- 在“统一技术措施”页按地点和用途查出候选值；确认后驱动页面正文和 Word 导出。查表数据是 AI 整理摘录，正式采用前仍需核对现行正式规范。
- 点击“导出 Word (.docx)”生成《结构计算统一措施》，页面尺寸、页边距和双栏参数按人大参考文档设置。
- 阅读版不显示 `source_id`、陈述类型和原文定位；这些审计字段完整保留在内嵌 AI 数据层中，可用“复制 AI 参数表”或“下载 JSON”获取。
- Word 网页版可切换两份文档，并按 A3 横向页面打印或导出 PDF。
- PPT 网页版可切换完整技术版和领导汇报版，支持按钮、滑杆及方向键翻页。
- 页面只显示 `[1]` 形式的数字引用，完整资料名称集中列在“参考资料”。

## 数据原则

原始资料只读。所有知识结论内部绑定 `source_id`，并区分原文事实、作者观点、我的观点和 AI 推断。外部统一措施只作为参考总则，项目数值以当前项目资料和用户确认记录为准。
