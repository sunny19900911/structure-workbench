## 改动

1. `deploy/portable/portable-service-lock.mjs` 使用 OS 命名管道互斥，键为经过 realpath 的数据目录；Windows 路径大小写归一。锁在 `start.mjs` 服务入口取得，覆盖启动器和 MCP，不只依赖 MCP 进程内 starting。后到者通过管道取身份、再校验 HTTP health 的 dataRoot/version/PID/instanceId。崩溃自动释放，不按 PID 判断陈旧锁、不删锁文件、不杀其他程序。不同目录可并存。
2. `launch.ps1` 只委托入口 `--open`，日志用独立 UUID，避免并发覆盖。服务占用端口时尝试后续端口；启动错误释放锁，正常关闭待 HTTP 停止后释放。
3. `workbench_status` 纯读；新增显式 `workbench_start`（只启动服务），保留 `workbench_open`（服务及网页）。业务读取在服务未启动时返回 `SERVICE_NOT_RUNNING`。工具清单、SDK instructions、连接说明与配置验收脚本同步更新；现有配置字段无需变更。
4. 页面连接 TTL 从 12 秒放宽到 120 秒。状态区分 connected/unresponsive/busy；visibilitychange 隐藏不注销，恢复前台、pageshow、online 立即轮询。请求有 15 秒传输超时，轮询防重入。
5. 保留 claim/start/deadline/token/revision；网页在异步前置读取后再次检查期限，未开始的过期写入不执行。已运行超时保留 outcome_unknown，阻止同项目新写入；完成回执丢失只重送回执，不重执行业务。清理 abort 监听，错误任务回执不释放其他运行任务的 busy。
