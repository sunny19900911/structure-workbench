## 实现与复用

- `requirements.py`：`extract(path)` 提取有 SHA256/source_id、OOXML part/XPath 的章节、表格、内嵌图片图位及页面/标题格式；`compare(reference, actual)` 对照实际 DOCX；CLI 输出 JSON 和简短检查表。
- 直接调用当前 `server/word-source.py` 的 `extract`，复用标题样式继承、表格逻辑列/合并、正文顺序及安全 XML 解析。新增的是结构要求整理及保守匹配，不另造 Word 转换服务，不执行文档指令。
- 参考 `design/reference-expansion/distill.py` 的去历史内容原则，以及 `verify-native.py` 的 OOXML 表格/页面几何核验方式。未运行 distill.py，避免改写共享派生模板。
- 不复制正文工程取值、表格工程数值或图片内容到要求清单。仅保留标题/题注、格式属性和位置。样稿是观察依据，所有条目 `mandatory=false`；隔震、装配式、高层等条件及特定单体沿章节传给子项。
- 历史 Word 存在正文套用标题样式的情况：长句和叙述句不进入章节要求，原位置记为 `excluded_candidates`。无图像关系的绘图对象不冒充图片；没有题注或同名歧义时不按序号强行配对。
- 同章同名匹配忽略编号和空白；比较标题层级、顺序、存储的字体/段落属性、表格列宽/属性、图片尺寸、纸张边距和分栏。同一表行数相同才比较完整合并/表头结构；项目数据行数不同仅记录，不自行判漏行。

不增加逐项确认或填写理由。产品入口及 MCP 注册本轮未做；这两个独立函数可以在后续讨论通过后复用。

- 完整来源路径、哈希及每个定位见 `examples/existing-reference-validated/requirements.json` 和 `actual-structure.json`；直接可读结果见 [检查结果](examples/existing-reference-validated/检查结果.md)。没有当前项目资料，所以参数对应关系明确暂缓。
- 样稿提取到 62 个标题、27 张表、15 个有图像关系的图位和 1 组页面设置；另保留被排除候选的位置。原文件中的 drawing 元素有 22 个，不能直接说成 22 张图片。

- 页纸尺寸、边距、分栏在本次所查属性中一致；未匹配项可能是改名、移章或不同适用范围，不自动认定漏项。

## 验证与限制

8 项针对性测试通过，覆盖历史数值不提升为要求、误用标题样式、条件继承、歧义/无题注、多节不强配、真实表格合并/页边距差异、章节顺序、源文件哈希和 XPath。`verify_example.py` 另对两个真实文件复提取，核对保存结果、全部要求定位及原件哈希。

直接运行原有 `design/reference-expansion/verify-native.py` 对上述历史 DOCX **未通过**：第 15 表（模板 19）23 行仍带 `tblHeader`，而当前校验器要求去除。这是旧导出与当前规则的实际差异，未当成通过，也不据此认定当前生成器有同一问题。

未验证或未实现：新同事样稿泛化、当前项目内容完整性、参数位置映射、规范适用性、正文全字体和样式全等、页眉页脚、文本框/内容控件内完整结构、分页与视觉排版、无图像关系的矢量绘图。多节文档保留各节设置，但没有足够语义依据时不自动配节。DOC/DOCM 等格式需后续上层先复用 `readWordSource` 转为受控 DOCX；本模块只处理 DOCX，不启动 Word 或执行宏。

## 运行

使用 bundled Python（含 lxml、Pillow、python-docx），从 `web-demo` 执行；不安装新依赖：

```text
python -B -m unittest discover -s design/parallel-review-20261111/sample-requirements -p test_*.py -v
python -B design/parallel-review-20261111/sample-requirements/verify_example.py
python -B design/parallel-review-20261111/sample-requirements/requirements.py --sample <样稿.docx> --actual <实际导出.docx> --output <全新的结果目录>
```

CLI 只新建结果目录，拒绝覆盖已有结果。单独提供 `--sample` 可只生成样稿结构清单。输出不写任何项目分区，不改变当前参数或成果。
