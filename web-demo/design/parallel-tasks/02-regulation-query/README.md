## 本地运行

真实联网核查必须启动本任务自带的只读服务。在 `prototype` 目录执行：

```powershell
node .\server.mjs
```

浏览器打开 `http://127.0.0.1:4177/`。直接双击 `prototype/index.html` 只能看到界面，不能执行真实联网核查；页面会明确显示“联网服务未启动”。

全国 31 个省级地区（不含港澳台）共用同一个工作台页面，不另建工作台或独立模块。M9 只读快照共 306 项；“覆盖 31 地区”不代表各地目录已经收全。正式入口直接输入省、市或省会名称并回车；结果表只显示规范名称及编号、发布/执行状态和权威原始网页。

如需审阅本轮四省检索过程，在 `web-demo` 的本地服务下打开：

`http://127.0.0.1:5174/design/parallel-tasks/02-regulation-query/process-review/`

修改原型脚本后，重新生成浏览器脚本包：

```powershell
cd C:\Users\mj528\Documents\004 工作\web-demo
npx.cmd vite build --config .\design\parallel-tasks\02-regulation-query\prototype\vite.bundle.config.mjs
```

规则测试：

