# iMA“三院结构规范”对照基准

本目录只保存从用户已授权的 iMA 共享知识库“三院结构规范”中整理出的目录、覆盖对比和方法迭代记录，不保存登录密钥，不把 iMA 问答结果直接当作规范有效性结论。

## 文件职责

- `三院结构规范-地方规范基准目录.md`：按省市排列、便于人工阅读的目录。
- `北京-目录对比与缺漏.md`：天津检索方法迁移到北京后的逐条覆盖对比。
- `上海-目录对比与缺漏.md`：修正方法迁移到上海后的逐条覆盖对比。
- `五省目录交叉比对.md`：天津、广东、江苏、浙江、云南定向清单及天津双基准对比。
- `iMA省级范围扫描.md`：全国概览与逐省定向清单数量差异、零命中复查记录。
- `第二轮增量反查.md`：第二轮模型候选、机器判重结果与真实新增清单。
- `第三轮专业词簇反查.md`：第三轮换检索切面后的候选、判重和新增分型。
- `第四轮文件类型与年份反查.md`：第四轮按文件类型、年份分段反查及逐文件正文核对。
- `第五轮编号前缀枚举.md`：第五轮按编号前缀枚举、机器比对与正文复核。
- `第六轮高密度地区反查.md`：第六轮聚焦北京、雄安、江苏、山东、广东的连续编号、版本链与载体链缺漏。
- `第七轮版本链与载体链反查.md`：第七轮区分规范正文、独立条文说明、宣贯材料、应用通知和版本对比文档。
- `第八轮稀有载体与资料类型反查.md`：第八轮按文件扩展名、通知、要点、目录和汇编等载体反查。
- `第九轮地市级与新区编号族反查.md`：第九轮专项枚举省内城市、新区和特区的标准编号族与无编号导则。
- `地方规范检索方法迭代日志.md`：每轮新增入口、缺漏原因、规则修订和复测结果。
- `../prototype/catalog/catalog.json`：网页目录唯一结构化数据源。
- `../prototype/catalog/index.html`：本机只读网页查看入口。

本机服务启动后，目录网页地址为：`http://127.0.0.1:4177/catalog/`。

截至 2026-09-25，第九轮地市级与新区编号族反查后已录入29个有命中省级行政区、355条文件/材料实例；内蒙古、宁夏专项复查仍为“本轮未命中”。第八轮新增1条，第九轮新增13条，因此尚未达到连续两轮无新增的收敛条件。这些是发现目录，不是现行有效目录。

## 证据边界

| 信息 | 用途 | 是否可直接判定现行/废止 |
|---|---|---|
| iMA 知识库文件目录 | 覆盖率基准、发现遗漏 | 否 |
| iMA 问答回答 | 检索线索 | 否 |
| 省市住建部门、标准平台的发布/废止原文 | 状态证据 | 是，需保留原始网址、标题和日期 |
| 搜索引擎摘要 | 发现候选 | 否 |

目录记录必须保留 `source_id`。iMA 基准项使用 `SRC-IMA-SYJG-...`；权威网页证据另用独立 `source_id`，不得混用。
