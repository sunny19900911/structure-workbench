## 判重规则

1. 对标准编号统一大小写，并去除空格、斜杠、下划线、括号等格式差异后比较。
2. 编号相同即视为同一标准候选，不因文件名或问答表述差异重复建档。
3. 同编号不同载体保留多个文件实例；同名不同年份作为不同版本分别记录。
4. 无编号材料用“省市 + 完整标题”判重，并单列材料类型。
5. 任何新增都会把“连续无新增”计数清零；至少连续两轮全国反查均为0个真实新增，才可声明 iMA 基准层收敛。
