# 地方规范检索方法迭代日志

## 目标与停止条件

以 iMA“三院结构规范”的地方规范目录为对照基准，按“天津 → 北京 → 上海 → 其余省市”迭代检索方法。某省市只有在以下条件同时满足时才记为“基准覆盖完成”：

1. iMA 基准目录中属于该省市的文件均已逐条匹配到本地发现结果，或记录了明确的不可比原因；
2. 标准编号、历史版本、无编号政策/审查要点均纳入比对；
3. 同一文件的简称、旧编号、替代编号经过归一化后再计算覆盖率；
4. 现行/废止判断有权威网页证据，不能仅凭 iMA 或搜索摘要；
5. 未匹配项为 0，且对该省市执行一次反向抽查。

“覆盖 iMA 基准”不等于“该省市客观全量”。权威目录中新发现而 iMA 未收录的规范也必须保留，并标记为 `权威源新增`。

## 初始方法 M0（天津样本归纳）

1. 先建省市权威源注册表：住建部门标准定额栏目、发布公告、废止公告、地方标准信息平台、标准定额站、勘察设计协会。
2. 同时检索现行目录、历史目录、废止/复审公告、替代关系，不用“现行”筛掉旧版。
3. 检索对象覆盖 DB/DBJ/DBT、通知、条例、设计要点、审查要点、导则、图集。
4. 由新版反查旧版、由废止清单反查历史文件、由文件原名反查编号和发布页。
5. URL 失效时回到栏目、站内搜索和同标题公告，不把 404 等同于废止。
6. 每条记录区分“目录发现证据”和“状态判定证据”。

后续每轮只记录相对上一版的增量修订，保留失败路径和漏项原因。

## M1（北京）相对 M0 的新增

- 单一住建源扩展为“住建委 + 规划自然资源委 + 市场监管局 + 全国标准平台”。
- 标准号先归一化空格、斜杠、下划线，再做精确检索。
- 增加状态 `将废止`、`有更新版`、`状态冲突`，避免二值化误判。
- 以 iMA 8 个归一化标准为覆盖分母，补检后发现层面达到 8/8。

## M2（上海）相对 M1 的新增

- 将地方编号体系本地化：`DGJ08` 与 `DG/TJ08` 是上海工程建设标准的主要扫描入口。
- 增加专业簇矩阵，避免只搜“结构/抗震/地基”造成系统性漏项。
- 每次动态获取最新已完成年度复审；截至本次核查，应用 2025年度结果，2026年度启动通知不算状态结论。
- 增加“知识库日期与权威公告差值”检查；发现 DG/TJ08-2071-2016 的 iMA 废止日期比官网早一个月。

## M3（全国编号前缀反查）相对 M2 的新增

- 单轮省名查询不能作为完整目录。北京首轮只得到8个不同标准，全国扫描又新增 `DB11/T 882-2012`、`DB11/T 1831-2021`。
- 每省执行三路检索：`省名+地方规范`、`本省编号前缀`、`全国省份/编号反向扫描`，三者取并集。
- 收敛标准由“AI声称全部”改为“连续两轮三路检索无新编号”；任何新增都会重置该省收敛计数。
- iMA 全国扫描可命中28个省级行政区；内蒙古、宁夏、黑龙江暂未命中，只能记为“未命中”，不能断言库内不存在。
- 发现一条文件名写“黑龙江”但编号为 `DB22` 的冲突项；M3阶段先进入归属冲突清单，没有自行改名。M5正文核读后确认正文实际编号为 `DB23/T 1318-2020`，文件名中的 `DB22` 是误写，归属修正为黑龙江并保留纠错证据。

## M4（定向复测与双基准交叉）相对 M3 的新增

- iMA“全国省份及命中数量”只能用作省份导航，不能用作统计基准。其概览曾将天津报为1条，五省定向检索却返回14条；广东由12增至20、江苏由5增至15、浙江由8增至14、云南由1增至2。
- 每省必须保存逐条原始名称清单，再由清单计算数量；禁止直接抄取问答中的汇总数。
- 检索至少包含四层：省名、标准编号前缀、结构专业词簇、历史/废止/替代词簇。问答中出现“全部”不构成收敛证据。
- iMA目录与用户本地资料目录互为召回基准，二者都不是权威真源。iMA偏向技术标准历史文件，本地天津资料还包含审查要点、行政通知、条例和较新版本；两者必须取并集后再访问权威网页核验。
- 数据分为两层：`document_inventory` 仅证明发现过某个文件；`status_evidence` 才能证明发布、实施、废止或替代。前者不得提升为正式适用结论。
- 同号不同载体只合并为一个标准、保留多个文件实例；同名不同年份不能合并。无编号资料（目录、审查要点、通知、汇编）单列材料类型，不能混入标准数量。
- 新的收敛条件：省名/前缀/专业词/历史词四路检索连续两轮无新编号，且本地资料与iMA未匹配项均已记录原因；随后才进入权威源状态核查。

## M5（全国分批定向扫描）相对 M4 的新增

- 将全国概览改为路线图后，按省份小批量执行逐条清单检索。目录从概览声称的28地扩展为29个有命中省级行政区；内蒙古、宁夏经省名、全称、编号前缀、专业词和历史词复查后仍为“本轮未命中”。
- 省级汇总与逐条定向结果差距很大，例如重庆5→12、河北3→11、山东2→9、河南2→12、甘肃2→9、新疆6→8。以后不得引用概览数量作为覆盖率分母。
- 仅凭文件名不能解决归属冲突。`DB 22/T 1318-2020` 文件正文核读确认实际为 `DB23/T 1318-2020` 黑龙江标准；正文证据可纠正文件名，但必须保留原文件名误写说明。
- 省级目录允许纳入辖区内地市级工程建设标准（如沈阳 `DB2101`、`SYJG`），但需在 `jurisdiction_level` 中区分省级与地市级，避免把适用范围扩大到全省。
- 征求意见稿、技术导则、协会/团体编号、无编号文件不与正式地方标准混算，分别标记 `draft`、`guidance`、`group_standard_candidate`、`unidentified_code`。
- “本轮未命中”必须附本轮检索词与前缀，不等于知识库不存在，更不等于该地区客观不存在地方规范。

## M6（第二轮增量反查）相对 M5 的新增

- 第二轮按全国省级编号前缀和结构专业词复查，iMA 自报16条“新增”；本地机器判重后只有14条是真新增。`DB11/T 1831-2021` 与 `DBJ50-047-2016` 早已收录，证明问答模型会遗忘本对话前文，不能承担目录判重。
- 增量处理固定为两阶段：先保存模型召回候选，再对 `standard_key` 做机器匹配。编号归一化至少去除空格、斜杠、下划线、括号和大小写差异；命中既有编号时不得新建记录。
- 同名不同年份必须分别保留。例如北京 `DB11/T 825-2015` 与 `DB11/T 825-2021`、天津 `DB/T29-204-2021` 与用户本地资料中的2026版线索，均先建立版本候选，替代与废止关系等待权威公告确认。
- 本轮真实新增分布为北京7、天津2、浙江2、河北1、四川2；其余已扫描地区本轮没有真实新增。由于本轮仍出现新增，连续无新增计数归零，当前不得宣称目录收敛。
- 下一轮应改变检索切面，避免重复相同问题：改用“编号前缀 + 专业词簇 + 年份区间 + 历史/替代/废止词”，并将候选与本地目录自动比较；只有连续两轮全国反查均为0个真实新增，才进入“iMA基准收敛”状态。

## M7（第三轮专业词簇反查）相对 M6 的新增

- 不再要求iMA判断“新增”，而是允许返回重复项；检索结果统一交给本地目录判重。这避免了M6中模型遗忘前文导致的假新增。
- 专业词簇扩展为荷载、抗震、减隔震、鉴定加固、地基基础、岩土勘察、基坑、边坡、桩基、混凝土、钢结构、装配式、砌体、木结构、幕墙、地下工程、防水、住宅、绿色建筑、超限、施工质量验收，并叠加旧版、修订、替代、废止。
- 87条本省候选中，编号或标题归一化后82条已存在，5条为真实新增：北京 `DB11/T 1746-2020`、上海 `DGJ08-81-2015`、江苏 `DGJ32/TJ208-2016`、福建 `DBJ13-107-2008`、湖北无编号的2025年施工图审查常见问题汇编。
- 无编号汇编可以进入“发现目录”，但必须标为 `汇编材料，非地方标准编号文件`，不能与正式标准数量或有效状态混算。
- 第三轮仍检出新项，说明“省名+前缀+通用结构词”不足以覆盖历史版和细分专业；下一轮需从文件类型反查（规程、规范、标准、导则、要点、汇编、图集、通知）并按年份分段扫描。

## M8（第四轮文件类型与年份反查）相对 M7 的新增

- 逐省用本地编号前缀组合规程、规范、标准、导则、技术要点、审查要点、汇编、图集、通知、实施细则，并按2000年前、2000—2009、2010—2019、2020—2026分段补检。
- 本轮确认26条真实新增，其中既有正式标准，也有天津导则、安徽通知、山东/湖南图集、长沙与宜宾地市级导则。发现目录可以保留全部类型，面向设计人员的“适用规范”结果必须默认排除通知、汇编、图集和归属未核验候选。
- 对候选逐条打开知识库原文件，而不是只看搜索摘要。由此纠正 `CRB600H高延性高强钢筋应用技术标准` 为山西 `DBJ04/T374-2018`，并将文件名 `DB34848-2008` 校正为正文编号 `DB34/848-2008`；原文件名差异保留在说明中。
- 行政区层级必须独立记录：`DB1331/T025.5-2022` 属雄安新区，长沙轻质隔墙板导则属长沙市，`DB5115/T41-2020` 属宜宾市。它们不能自动扩大为全省适用。
- 文件类型词显著提高了召回，说明仅靠专业词仍会漏掉通知、图集、实施细则和地方导则。本轮新增26条，收敛计数归零。
- 下一轮不再继续堆叠关键词，改为“编号前缀文件名枚举”：按省级代码直接要求列出知识库内所有文件名，再由本地程序做编号/标题判重。这是对语义检索漏项的反向审计。

## M9（第五轮编号前缀枚举）相对 M8 的新增

- 按全国地方编号族直接枚举文件名，不限定专业主题；再把页面中的编号正则抽取，与本地 `standard_key` 自动比较。该方法从大量重复结果中筛出10条真实新增。
- 新增包括北京2、江苏1、广东1、山东2，以及雄安新区4条。雄安 `DB1331` 必须保存为新区层级，不能作为河北全省通用标准直接返回。
- 枚举中出现 `XJJ134（pdf_164）`，但打开文件后正文与文件名均为 `XJJ075-2016`；由于该标准已收录，错误候选不入库。由此新增规则：搜索回答中的“编号—文件ID”映射也必须正文复核。
- 山东 `JD37-001-2023` 文件名误写“山地省”，正文确认为《山东省建筑防水工程技术导则》；目录保存纠错说明，不改写原始文件名证据。
- 本轮仍新增10条，连续无新增计数为0。下一轮应重点对本轮正则发现但标题不完整、以及编号密集地区（北京、雄安、山东、广东、江苏）做反向遗漏审计。
