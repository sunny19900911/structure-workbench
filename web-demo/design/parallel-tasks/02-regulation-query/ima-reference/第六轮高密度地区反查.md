## 方法修订

1. 编号归一化后仍需保留前缀语义差异，尤其 `/T` 不能凭问答回答自动补写。
2. 无编号文件必须打开正文补全编号；补全编号不等于新增文件实例。
3. 宣贯材料、修订依据论文、条文说明可用于发现版本链，但不能冒充规范正文或状态证据。
4. 长回答发生截断时，只处理能完整提取并逐份核对的部分；不得推测截断内容。
5. 本轮有新增，收敛计数归零；下一轮切换为“替代关系 + 载体链”反查。
