## 本轮确认的漏项成因

1. AI汇总数量不是数据库计数，前序检索页数和关键词不同会导致数量漂移。
2. 省名查询召回不稳定；编号前缀、专业名和历史状态词必须补检。
3. 标准编号存在空格、下划线、全角斜杠、`DBT`/`DB/T`/`DBJ/T` 等写法差异，未归一化会产生假缺漏。
4. 知识库偏技术标准，本地项目资料同时覆盖通知、条例、审查要点和设计要点；两类目录口径不同。
5. 同号PDF/Markdown、条文说明、编制介绍会制造假重复；反过来，同名不同年份又可能是假合并。

## 下一轮执行规则

1. 先逐省导出原始文件名，保留载体与副本信息。
2. 用本省编号前缀补检，再用结构专业词簇和历史/废止词簇补检。
3. 与用户本地资料目录做双向差集；每个未匹配项记录“版本差异、材料类型差异、疑似同件、确实未发现”之一。
4. 只对取并集后的条目去省住建厅、市场监管局、标准定额站和全国标准信息公共服务平台做状态核验。
5. 权威网页未核实前，目录页面只显示“待核查”，不得显示为现行适用规范。
