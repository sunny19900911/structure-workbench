## 对方法的修正

1. “结构专业词”不能只用结构、抗震、地基、装配式；岩土勘察、钢结构住宅、质量通病、施工图审查等细分词会召回不同文件。
2. 历史词能找到当前目录漏掉的旧版，但iMA的“废止”标记只是线索，必须再查权威公告。
3. 目录层允许保存导则、要点、汇编等材料，但必须与正式标准分型；查询正式适用规范时默认不混入。
4. 下一轮改用文件类型词和年份区间，而不是重复本轮同一长查询。
