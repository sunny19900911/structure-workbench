## 方法修订

1. 每省除省级前缀外，再扫描辖区内城市代码、特区编号、新区编号和无编号市级导则。
2. 直辖市标准按省级层级处理；省内城市标准另记 `jurisdiction_level=city/new_area`。
3. 每批定点核验最多5个文件，避免长回答截断或重复生成。
4. 市级文件只证明对应城市/新区范围，不能扩大为全省适用。
