# 地方规范检索方法 M3：项目反查与版本闭环

更新时间：2026-09-26  
适用范围：任务二“地方规范查询”候选发现、状态核验和主工作台回写。  
本轮校准基准：`E:\600-工作台数据库\610-待处理\各省地方规范汇总.docx`（原始资料只读）。

## 1. 本轮得到的结论

旧方法把“省级工程建设地方标准目录”当作主要入口，能找到一部分 DBJ/DGJ，却系统性漏掉四类资料：

1. 历史项目实际采用、但未进入搜索引擎热门结果的旧版标准；
2. 条例、政府令、通知、技术要点、导则和标准图集；
3. 官网按专业板块拆分的目录，以及藏在目录附件中的 PDF；
4. 只在新版发布公告、废止公告或后续官方文件中出现的替代关系。

610 项目基准共提取 40 项：云南 15、江苏 4、上海 9、海南 12。旧工作台清单与其直接重合仅 5 项；本轮形成 29 项可回写记录，另外 11 项因没有找到足够强的权威原页或有效性证据而留在待核台账，不写成“现行”。

## 2. M3 检索顺序

### 第一步：项目资料反查

- 从历史项目的设计说明、统一技术措施、审查回复和规范清单中抽取原始名称、编号、年份、文号。
- 项目资料只证明“曾被项目采用”，不自动证明当前仍有效。
- 无编号的会议纪要、内部通知也保留，不因难检索而丢弃。

### 第二步：名称和编号归一

- 统一全角/半角、`—`/`-`、`DBJ 46-08`/`DBJ46-008`、`DB 53/T`/`DBJ 53/T` 等写法。
- 同时保存原始写法和归一写法，避免因编号格式差异漏检。
- 对同一编号族按年份枚举，例如 `DG/TJ08-32-2008 → DG/TJ08-32-2025`。

### 第三步：权威目录枚举，不只做关键词搜索

- 省住建厅工程建设标准栏目：逐页、逐专业板块枚举。
- 省市场监管局/全国标准信息平台：核 DB/DBT 状态。
- 省人大、省政府规章目录：核条例和政府令。
- 省厅通知公告：核发布、修订、废止、复审和过渡条款。
- 省工程建设标准站/协会/正式出版库：只能作为候选发现或交叉证据，不能单独升级为正式“现行”。

本轮实例：云南官网把现行标准拆成“岩土工程与地基基础”“建设工程防灾（减震隔震）”“绿色建筑与建筑节能”等板块；只查一个总目录会漏掉 DBJ 53/T-47、48、70、125 等。

### 第四步：附件反查

- 当官网站内搜索失灵时，从目录页、镜像页或搜索结果中只提取线索，再回到主管部门域名的 PDF/附件作为证据。
- 镜像网页不得作为正式状态结论。
- 本轮实例：海南目录镜像暴露了 `zjt.hainan.gov.cn` 的正式 PDF 地址；正式记录只保存省住建厅 PDF，不保存镜像页为结论证据。

### 第五步：建立版本链

对每一项同时搜索：

- `名称 + 编号`
- `名称 + 废止/替代/修订/复审`
- `旧编号 + 新年份`
- `新版发布公告 + 原标准同时废止`
- `后续官方文件 + 旧文件编号`

必须把旧版和新版都作为独立记录展示。上海 `DG/TJ08-32-2008` 不能只标“非现行”，应显示其自 2026-05-01 被 `DG/TJ08-32-2025《高层建筑钢结构设计标准》`替代。

### 第六步：状态证据分级

| 状态 | 允许的证据 | 页面表达 |
|---|---|---|
| 现行 | 权威现行目录、现行规章目录，或明确发布且无后续冲突 | 现行 |
| 已废止/已替代 | 权威废止公告、新版发布公告明确写明旧版废止 | 已废止/已替代 + 日期 + 新名称和编号 |
| 新项目已替代 | 新文件给出明确过渡日期和适用范围 | 新项目已替代 + 起算日 + 新文件 |
| 待核实 | 只找到官网原文、后续官方引用、正式出版库或协会目录 | 简短说明证据边界 |
| 未解决 | 只有项目资料或非权威转载 | 不进入正式结论；留在待核台账 |

“规划期届满”“年度工作已结束”不是法律意义上的“废止”；二者不得混写。

### 第七步：负证据规则

- 搜不到不等于已废止。
- 不在某一个目录中不等于已废止，除非该目录明确声明完整性和状态口径。
- 后续官方文件引用可以证明“当时仍被使用”，不能单独证明核查日仍现行。
- 出版库或协会标注“现行”只能先进入待核。

### 第八步：回写工作台

- 有权威原页且结论足够清楚的记录写入模块③。
- 证据较弱但对设计有价值的记录以“待核实/仍被官方引用”进入试用快照，不冒充已确认现行。
- 只有转载或项目资料的记录留在候选台账，等待人工确认或找到权威原页。
- 所有记录必须包含 `source_id` 和可打开的 `source_url`。

## 3. 四省漏项修正

### 海南

- 漏因：官网站内检索命中率低；标准 PDF 集中在附件目录；政策文件原页迁移或未被索引。
- 修正：目录枚举 → 镜像仅发现链接 → 回到省厅 PDF；对年度政策和规划单列，不混进“现行标准”。

### 上海

- 漏因：只查标准名，没查发布通知与过渡条款；历史项目中的政策文件未进入 DBJ 目录。
- 修正：标准编号族 + 发布通知 + 装配式政策替代链三路核对。

### 江苏

- 漏因：省厅没有稳定公开的统一现行目录；项目使用的 DGJ32/TJ 文件在官方搜索中命中较差。
- 修正：省厅废止公告优先；省人大条例目录独立查；市级官方文件和出版库只作“仍被引用/待核”证据。

### 云南

- 漏因：官网按专业板块拆分；大量适用依据是政府令、技术要点、导则和图集，不属于普通标准目录。
- 修正：逐板块枚举 + 法规规章目录 + 审查回复反查 + 新旧编号族闭环。

## 4. 收敛标准

某省只有同时满足以下条件，才可称为“本轮覆盖完成”：

1. 项目基准中的每一项都有“已核实 / 待核实 / 未解决”结论；
2. 每个旧版都检查了新版、废止公告和同编号年份链；
3. 每个“现行”均有权威源；
4. 每个“未解决”均记录已查渠道和下一步，不静默丢弃；
5. 主工作台只消费已核实或明确标注证据边界的记录。

本轮四省已完成 40/40 项的逐项建账，但仍有 11 项处于“未找到足够强权威原页/有效状态证据”，因此方法已升级，资料核验尚未宣称全量闭环。
