# 原型忠实度记录

## 定位

本原型只验证模块③“整理地方规范”的地区查询、权威网页联网核查和 ③-C 候选流程，不是新的工作台。正式入口仍为 `workbuddy-integrated-studio.html`。

## 本轮界面收口

依用户反馈，页面已经删去：

- “地点门禁”说明块；
- 查询数量、候选数量与时间统计条；
- 来源运行卡片；
- 右侧“规范来源”证据栏；
- 角色、阶段、模块状态和场景按钮。

当前只保留：

- 右上角一个重点省份下拉筛选；
- 左侧地区输入、确认和联网查询；
- 中间四列表格：适用层级、规范名称及编号、有效状态（发布/执行）、权威原始网页；
- 下方 ③-C“联网发现→601 候选→内容核验→负责人确认→601 正式库”。

## 主工作台接入

模块③现以同一个输入框查询天津、北京、上海、广东、江苏、浙江、云南，共 57 条只读核验记录；没有新增省份按钮、独立页面或第二套导航。所有明确写出替代编号的旧版记录，其新版均在同省结果中作为独立记录展示。广东、浙江仅有发布/实施证据而缺少当前现行目录证据的条目，页面标为“已实施，现行待核”，不升级为“现行”。

## 可信边界

- 只有主管部门现行目录、复审结果或全国标准信息公共服务平台明确标注“现行”时，页面才显示“现行”。
- 仅有发布公告和实施日期的记录显示“已发布 / 已执行”，不据此声称核查日仍现行。
- 查询未命中不等于废止。
- 页面实时访问白名单权威网址并记录获取时间与内容哈希，但结果仍是 601 候选，必须经过 ③-C 人工核验与批准。
- 不展示参数、不回填①、不写入 601 正式库。
