# 检索过程审阅页视觉核对记录

核对日期：2026-09-26  
概念图：`process-review/concept.png`  
实现截图：`process-review/desktop-1440x1000.png`、`process-review/mobile-390x844.png`

## 已核对的关键点

1. 顶部保持“标题 + 四省文字切换 + 核查日期”，没有侧栏、二级导航或装饰图标。
2. 首屏保留四个核心数字：项目基准、旧清单覆盖、本轮进入工作台、尚未进入工作台。
3. 五步方法链保持与概念图一致：项目反查、编号归一、目录枚举、版本链、分级回写。
4. 主体仍是逐项对比表，且每一行都显示具体核查渠道、结论和原页/待补状态。
5. 下方保留“为什么会漏”“方法如何修正”“实际检查渠道”和 M1/M2/M3 演进，不增加新的功能区。

## 首屏文案差异

- 概念图写“权威核验后/新增待确认”，实现改为“本轮进入工作台/尚未进入工作台”，避免把待核记录误读为已经权威确认。
- 概念图使用演示数字，实现在四省切换时显示真实的 610 基准数字。
- 实现补充“这里不是第二个正式工作台”和证据边界说明，符合任务上位约束。

## 有意偏差

- 概念图底部另设“待确认项”表；实现将待核与未解决项直接保留在同一逐项表中，避免重复列表和多余标签。
- 实现没有复刻概念图的浅蓝渐变，只使用纯色浅蓝背景和细线，保持页面更简洁。
- 手机端表格采用区域内横向滚动；页面本身无横向溢出，避免把五列压成难读的卡片。

- 手机：390 × 844，无页面级横向溢出；四省切换、数字摘要和 12 条海南项目均正常渲染。
