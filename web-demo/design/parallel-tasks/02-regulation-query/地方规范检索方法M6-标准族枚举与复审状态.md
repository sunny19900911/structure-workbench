# 地方规范检索方法 M6：标准族枚举与复审状态

更新时间：2026-09-26  
上位方法：`地方规范检索方法M5-批次扩省与临界实施日.md`  
适用范围：地方工程建设标准发现、版本链核验、复审状态解释和主工作台只读展示。

## 1. 本轮新增规则

1. **按标准族枚举，不按单个标题搜索。** 一个项目种子应扩展为“地基/桩基/岩土/抗震/减隔震/装配式/既有建筑/质量通病”等标准族，再分别使用编号、旧标题、新标题和主题词检索。
2. **新年份不自动等于现行。** 必须打开权威状态页读取废止日期。山东 `DB37/T 5055-2024` 虽为 2024 版，但全国标准信息公共服务平台显示 2026-06-05 废止。
3. **“复审结论：修订”不等于废止。** 在新标准正式实施或主管部门明确废止前，不能把“修订”直接改写成“非现行”；页面应原样显示复审结论并继续核查。
4. **发布证据与状态证据分开。** 省厅发布页可证明名称、编号和实施日；全国标准平台或主管部门废止公告用于确认现行/废止。只有发布证据时，状态降为待核实。
5. **替代链必须闭环。** 旧版显示“已替代”时，工作台中必须有新版的独立记录，同时展示新版编号和完整名称。
6. **地方标准、工程建设地方标准、导则和图集分流。** `DB/DBJ` 标准进入默认清单；导则、图集、协会文件和征求意见稿只留候选，不冒充正式标准。

## 2. 检索闭环

1. 从 iMA/历史项目提取种子，记录原始标题与编号；
2. 按省份识别编号族，例如福建 `DBJ/T 13`、山东 `DB37/T`、武汉 `DB4201/T`；
3. 以“编号精确检索 + 标题词检索 + 标准族主题词”三路召回；
4. 先查省级住建主管部门发布/复审/废止栏目，再查全国标准信息公共服务平台；
5. 对每条记录查找“全部代替标准、废止日期、有更新版、同时废止、复审结论”等字段；
6. 建立旧版—新版双向关系，并核对新版是否已经实施；
7. 无权威状态证据的条目保留为 `pending`，不因出版库、项目引用或搜索摘要而升级；
8. 把已确认记录写入任务二只读快照；候选仍走 601 候选—人工确认流程。

## 3. 本轮省级差异

- 福建：发布通知附件常一次列多项标准，并在“备注”中写旧版同时废止，适合批量建立版本链。
- 江西：公开搜索对工程建设地方标准召回较弱，省厅原始发布页不稳定；本轮只确认“已发布/已收录”，状态不越级。
- 山东：全国平台对废止日期较完整，且出现“新版实施后不久又废止”的异常链，必须逐条看状态页。
- 河南：省厅标准公开库适合发现全文，但现行总目录与废止链仍需单独核对，不能把“库中可下载”等同于现行。
- 湖北：省厅公告可直接给出旧版同时废止；同时要补查武汉 `DB4201` 城市级标准。
- 湖南：正文可证明标准存在，但当前有效状态总表检索性不足，本轮全部保留待核实。
- 广西：复审结果会给出“继续有效/修订/废止”等不同结论；其中“修订”只是工作状态，不是废止结论。

## 4. 601 字段/API增量需求

- `standard_family`：地基、桩基、抗震、装配式等主题族；
- `publication_evidence` 与 `status_evidence` 分离；
- `review_conclusion`：继续有效/修订/废止/未复审；
- `review_date`、`next_review_due`；
- `supersedes_codes`、`superseded_by_codes`；
- `authority_level`：省级、设区市、新区；
- `document_kind`：standard/guideline/atlas/notice/draft；
- `status_as_of_date` 与 `status_confidence`。

网页检索只能发现候选。没有人工确认和权威状态证据，不得写入 601 正式结论，也不得直接提供给 DeepSeek 作为确定性规范结论。
