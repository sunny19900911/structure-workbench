## 1. 结论

这批天津资料的主要来源不是普通搜索引擎，也不是第三方规范下载站，而是以下四类权威入口：

1. 天津市住房和城乡建设委员会“现行标准规范”栏目：工程建设地方标准正文、标准编号、实施日期、发布文号、备案号。
2. 天津市住房和城乡建设委员会“工程建设标准设计”栏目：施工图审查要点、标准设计技术文件及正文。
3. 天津市住房和城乡建设委员会“政策文件 / 通知公告”栏目：行政规范性文件、效力状态、清理和废止公告。
4. 天津市人大法规来源和司法部备案信息：地方性法规的公布、施行及备案证据。

检索其他省份时，应复制的是这套“栏目定位 + 编号检索 + 发布证据 + 废止证据”方法，而不是复制天津的 URL 结构。各省网站结构不同，但证据链基本一致。

本次最重要的实证发现是：本地保存的《关于贯彻执行〈中国地震动参数区划图〉的通知》（津建设〔2016〕256号）已经被天津市住建委于 2022-12-19 明确列入废止目录。文件仍在本地、仍被旧审查资料引用，都不能证明它当前有效。

## 4. 从天津资料学到的可复制检索方法

### 4.1 先从文件中抽取四个定位键

按可靠性排序提取：

1. 标准号或文号，例如 `DB/T29-320-2025`、`津住建设〔2022〕9号`；
2. 完整标题；
3. 发布/批准机关；
4. 实施日期、备案号或被替代标准号。

不要只按“天津 + 抗震规范”搜索。优先查询精确编号：

```text
site:zfcxjs.tj.gov.cn "DB/T29-320-2025"
site:zfcxjs.tj.gov.cn "津住建设〔2022〕9号"
site:zfcxjs.tj.gov.cn "津建设〔2016〕256号" 废止
```

### 4.2 找到文件后，必须反向定位稳定栏目

单个 PDF 地址可以证明正文来源，却不适合持续发现新标准。应从详情页或附件 URL 反向找到主管部门的：

- 现行标准目录；
- 标准发布公告；
- 标准复审结果；
- 废止或清理公告；
- 政策文件库及效力状态；
- 工程建设标准设计 / 审查要点栏目。

天津“现行标准规范”页的页面数据中还直接提供标准编号、标题、主编单位、实施日期、发布文号、备案号和 PDF 地址，适合做只读发现器，但网页结构变化后仍需人工维护适配器。

### 4.3 状态核验必须与正文发现分开

每一条候选至少执行以下核验：

1. 发布：是否有主管部门发布公告或现行目录记录；
2. 实施：实施日期是否已到；
3. 替代：发布公告是否写明原标准同时废止；
4. 复审：是否有“继续有效、修订、废止”的复审结果；
5. 清理：政策文件是否出现在行政规范性文件清理/废止目录；
6. 冲突：较新文件是否仍引用已废止文件；若有，保留冲突并交人工确认。

“未检索到”只能写“未命中/待核实”，不得推断为废止；“被新文件引用”也不能推断为现行。

### 4.4 证据等级

| 等级 | 证据 | 可做什么 |
|---|---|---|
| A | 省级住建主管部门现行目录、正式发布公告、复审/废止公告、法规效力库 | 形成高可信候选状态 |
| B | 主管部门官网 PDF 正文、政府信息公开页、人大/司法部备案 | 核对身份、正文、公布与实施信息 |
| C | 省标准定额站、建设科技中心、勘察设计协会官网 | 补充发现导则、图集、培训资料；不能单独确认效力 |
| D | 搜索引擎摘要、公众号、文库、第三方下载站 | 只做线索，不进入正式结论 |

## 6. 形成全国来源注册表的操作模板

对每个省级行政区执行同一套步骤：

1. 确认省级住建厅/委官方域名和政府网站标识；
2. 在官方域名内查找“工程建设地方标准、现行标准、标准定额、标准设计”；
3. 查找“发布、实施、复审、继续有效、修订、废止、清理”等状态栏目；
4. 用该省编号前缀测试一个结构专业样本，例如 DB11、DG/TJ08、DGJ32、DB33、DBJ51、DBJ/T15；
5. 验证详情页或附件是否给出名称、编号、批准/发布日期、实施日期、备案号和正文；
6. 记录栏目 URL，而不只记录某一个 PDF；
7. 将省标准定额站、建设科技中心、勘察设计协会登记为补充源；
8. 找不到废止证据时保持“待核实”，不自动判为现行；
9. 每条候选保留抓取时间、原始 URL、内容指纹和人工确认状态。

推荐的站内检索模板：

```text

site:<省住建厅官方域名> "工程建设地方标准" "复审"

site:<省住建厅官方域名> "具体标准号"

```

## 7. 对 601 候选流程的字段需求

本任务不修改 601，只提出最小字段需求：

- `jurisdiction`：省/市及适用行政区；
- `document_type`：地方标准、地方性法规、行政规范性文件、审查要点、导则、图集；
- `standard_no` / `document_no` / `filing_no`；
- `title`、`issuing_authority`；
- `publication_date`、`implementation_date`、`repeal_date`；
- `status_claim`：发布、未实施、执行、继续有效、修订、废止、待核实；
- `status_evidence_type`、`status_evidence_url`、`status_evidence_quote`；
- `catalog_url`、`document_url`、`repeal_notice_url`；
- `retrieved_at`、`content_sha256`、`local_file_sha256`、`exact_file_match`；
- `source_grade`、`requires_human_review`、`reviewer`、`reviewed_at`；
- `conflicts`：保留“旧资料仍引用已废止文件”等冲突，不静默覆盖。

查询界面只显示规范名称、编号、层级和有效状态时，后台仍必须保留上述证据字段，以便 DeepSeek 输出可追溯引用。

## 8. 验收标准

一个省份只有同时满足以下条件，才标记为“来源入口已验证”：

- 至少一个省级住建主管部门官方栏目可访问；
- 至少一条工程建设地方标准能从编号追到官网记录或正文；
- 能找到发布/实施证据；
- 能找到复审、废止或清理入口之一；
- 每条结果包含原始 URL 和抓取时间；
- 没有用搜索摘要、协会转载或第三方下载站直接断言现行有效。

只有发布页面而没有复审/废止入口的地区，应标为“部分验证”；不得在前台显示为已经完成判废。
