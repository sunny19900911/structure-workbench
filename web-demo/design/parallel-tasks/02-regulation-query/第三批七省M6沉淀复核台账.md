## 3. 明确保留为待核实的记录

- 江西两项：可证明发布或国家平台收录，但未取得稳定的省厅现行总目录证据。
- 河南除装配式 2019 旧版外的九项：省厅公开库能证明存在，现行/废止状态仍需逐条公告核查。
- 湖南三项：正文或历史目录可查，但不能由“能打开”推断现行。
- 广西 `DBJ/T45-082-2019`：官方复审结论为“修订”，这不是废止；在新版实施前保持待核实。
- 福建、山东、湖北的若干历史种子：只有发布页、原始目录或国家平台搜索入口，未获取足以升级为现行的状态证据。
