# 真实联网核查实现说明

## 结论

`prototype/server.mjs` 是可运行的只读联网核查服务，不再使用静态“联网候选演示”。它实时访问白名单内的权威网站，返回规范名称、编号、发布/实施日期、状态依据、原始 URL、抓取时间和内容 SHA-256。所有结果仍是 601 候选，服务没有写入 601 的接口。

## 已接入来源

| 来源 | 实现方式 | 可判定内容 |
|---|---|---|
| 全国标准信息公共服务平台 | 调用官网高级检索接口，查询国家标准和行业标准 | 平台明确返回的现行、即将实施、废止状态及发布日期、实施日期 |
| 住房和城乡建设部文件库 | 调用官网公开文件库检索接口并读取公告正文 | 发布公告、征求意见稿、明确实施日期、明确替代/废止关系 |
| 天津市住房和城乡建设委员会 | 读取“标准公告”和“现行标准规范”官方栏目，并读取命中的详情页 | 发布、实施、征求意见，以及“列入现行标准栏目”这一状态依据 |
| 云南省住房和城乡建设厅 | 读取“云南省工程建设地方标准”官方专题及详情页 | 发布、公示、实施信息；不足时保持待核实 |
| 云南省工程建设科技与标准定额管理网 | 读取公开栏目，作为补充来源 | 地方技术要点、通知和标准线索；不能替代主管部门正式结论 |

天津市勘察设计协会尚未发现稳定且可追溯的公开检索入口。系统会显示“未配置”，不会用普通搜索引擎结果冒充协会权威源。

## 判定规则

1. 权威平台明确返回“现行、即将实施、废止”时，可按该状态生成候选结论。
2. 公告明确写明“自某日实施”时：日期尚未到则标记“未实施”；日期已到只标记“已实施·现行待核”。历史发布公告本身不能证明截至核查日仍现行。
3. 公告明确写明“原某标准同时废止”时，同时生成旧标准的废止候选，并保留替代关系和同一证据 URL。
4. 征求意见稿、立项公示、报批稿只能标为草案/公示，不能标为已发布执行。
5. 页面未提供足够依据、详情页无法读取或某来源未命中时，一律显示“待核实/未命中”，不得推断为废止。
6. 各来源冲突时保留全部记录，交由 ③-C 人工确认；服务不静默选择胜者。

## API

`GET /api/health`：检查只读联网服务状态。

`POST /api/discover`：

```json
{
  "province": "天津市",
  "placeId": "PLACE-TJ-BINHAI",
  "keywords": "建筑抗震设计规范\nGB 50011-2010",
  "asOf": "2026-09-25"
}
```

`keywords` 按换行、逗号或分号拆分，每行可填写一个待核验的规范名称、编号或发现关键词。响应中的每条 `record` 至少包含：`title`、`documentNo`、`status`、`statusBasis`、`sourceUrl`、`retrievedAt`、`fingerprint`、`queryTerm`、`requiresHumanReview`；`targetChecks` 逐项说明是否命中。未命中不等于废止。

- 云南输入“地基基础”后，云南省住建厅 2026-06-30 的“现行标准目录”被拆分为 12 条地方标准，并以主管部门现行目录作为状态依据。原始页：`https://zfcxjst.yn.gov.cn/ztzl/ynsgcjsdfbz/202606/t20260630_3273947.html`。

以上是联调时的在线抓取结果，保留原始 URL、抓取时间和 SHA-256，但仍属于 ③-C 候选，不等同于已经批准写入 601 的正式结论。

## 安全边界

- 仅允许访问代码白名单中的官方域名，避免把用户输入变成任意 URL 请求。
- 每次请求设有超时，并限制详情页抓取数量和最终候选数量。
- 不保存网页全文，不修改主工作台，不写入 601/603。
- 网站结构变化、反爬限制或临时不可用会显示为来源失败；这属于待核实状态，不改变规范有效性。
