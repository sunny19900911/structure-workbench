# 地方规范检索方法 M5：批次扩省与临界实施日

更新时间：2026-09-26  
上位方法：`地方规范检索方法M4-区域前缀与适用性门禁.md`  
适用范围：地方规范发现、状态判定、版本链补全和主工作台只读展示。

## 1. 本轮新增结论

M4 的五道门禁继续有效。本轮扩展重庆、河北、山西、辽宁、吉林、黑龙江、安徽后，再增加四条执行规则：

1. **状态必须绑定核查日。** `发布日期 < 核查日 < 实施日期` 时，不能显示“现行”，应显示“已发布，尚未实施”。
2. **新版发布不等于旧版立即废止。** 若公告明确旧版在新版实施日同时废止，旧版在实施日前仍显示“现行至 YYYY-MM-DD”。
3. **地方工程建设标准与一般地方标准双线检索。** 省住建厅 `DBJ/工程建设地方标准` 目录与全国标准信息公共服务平台 `DB` 目录互补，任何一条线都不能代替另一条。
4. **没有权威状态目录就降级，不猜测。** 出版库、历史项目或后续官方引用只能证明“存在/仍被引用”，不足以证明核查日现行。

## 2. 临界日期状态机

以 `as_of_date` 为唯一比较基准：

- 发布日期晚于核查日：不进入正式结果，仅留发现候选；
- 已发布、实施日期晚于核查日：`pending / 已发布，尚未实施`；
- 实施日期不晚于核查日，平台明确现行：`current / 现行`；
- 新版已发布但尚未实施，且公告明确旧版届时废止：旧版 `current / 现行至前一日`，并显示新版名称、编号；
- 废止或替代日期不晚于核查日：`non_current / 已废止或已替代`；
- 平台只显示“有更新版”但未给出废止日：以新版实施日和发布公告交叉核验；无法交叉核验时保留待核实。

本轮实测样例：

- `DB21/T 907-2026` 于 2026-09-30 实施；在 2026-09-26 的快照中，新版标“已发布，尚未实施”，2015 版标“现行至2026-09-29”。
- `DB23/T 4057-2026` 于 2026-09-28 实施；在 2026-09-26 的快照中不能提前标成现行。

## 3. 批次扩省步骤

1. 从 iMA/历史 Word 抽取候选，只作为召回基准；
2. 识别本省编号族及特殊区域编号，例如河北 `DB13/DB13(J)` 与雄安 `DB1331`；
3. 先查省住建厅发布/废止公告，再查全国标准信息公共服务平台；
4. 用标准编号和标题双向检索新版、旧版、替代词、废止词；
5. 对相同主题建立版本链，旧版与新版都保留独立记录；
6. 补扫项目资料未出现、但权威目录新增的结构相关标准；
7. 仅把有权威状态证据的条目标成现行/非现行；其余保留为待核实；
8. 运行快照—浏览器脚本一致性、替代对象存在性、入口回车行为测试。

## 4. 本轮学到的省级差异

- 重庆：发布公告经常在一页同时写明新标准、实施日和多个旧标准废止，适合直接构建一对多替代链。
- 河北：必须将雄安 `DB1331` 作为独立分支；只查河北省级 `DB13(J)` 会漏掉抗震、防水、基坑等新区标准。
- 山西：公开检索能找到标准正文或后续引用，但缺少稳定可检索的省厅现行状态总表，故本轮四项全部保留待核实。
- 辽宁：存在新版已发布、实施日尚未到的临界状态，必须按日计算。
- 吉林：全国平台可直接发现 2026 年废止状态，说明旧项目/iMA目录不能承担状态真源。
- 黑龙江：从一个 iMA 种子可沿同地区、同归口和相近标准扩展出地基、雪荷载、低能耗与地震资料规则等条目。
- 安徽：同一批结构标准中既有现行也有已废止项，不能按同批发布日期推断共同状态。

## 5. 601 字段/API增量需求（只提需求，不改核心库）

- `published_date`、`effective_date`、`repealed_date`；
- `status_as_of_date`；
- `future_effective`；
- `valid_until`；
- `status_authority`（主管部门公告/国家平台/后续官方引用/出版库）；
- `status_confidence`（confirmed/pending/conflict）；
- `replacement_codes` 与可解析的替代对象名称；
- `regional_branch`（province/city/new_area）；
- `discovery_source_id` 与 `status_source_id` 分离。

网页检索、iMA、历史项目和出版库都只能进入候选流程；未经过人工确认和权威状态证据核验，不得进入 601 正式结论。
