# 地方规范检索方法 M7：空白省份反向建库与低覆盖告警

更新时间：2026-09-27  
上位方法：`地方规范检索方法M6-标准族枚举与复审状态.md`  
适用范围：缺少历史项目种子、地方住建厅公开目录不完整、工程建设标准与普通地方标准分散发布的省级地区。

## 1. 本轮为什么还会漏

1. **iMA/历史项目不是全量目录。** 青海只有旧标准种子，宁夏和内蒙古没有种子；若只从项目反查，会把“没有样本”误判成“没有地方标准”。
2. **地方标准存在两套编号与两套入口。** `DBxx/T` 常进入全国标准信息公共服务平台，`DBJ/DBJ-T/XJJ` 工程建设地方标准则更多留在省级住建厅的标准定额栏目。
3. **发布页不能单独证明仍然现行。** 标准全文、公告或后续文件引用只能证明“存在/曾实施/仍被引用”；没有现行目录、复审结论或废止公告时仍须标为待核。
4. **复审目录不等于复审结论。** 新疆 2024 年页面列出待复审标准，只能显示“列入复审、结论待公布”，不能据此判废或判现行。
5. **旧版会被目录的“代替”字段反向发现。** 宁夏现行有效目录中的“代替 DB64/521-2013”等信息，必须反向生成旧版记录，才能同时回答“现在用什么”和“以前的版本何时失效”。
6. **公开源质量不均。** 宁夏有整表的现行/废止目录；内蒙古公开搜索更多命中正文、征求意见稿和后续引用。两省不能套用同一置信等级。

## 2. M7 检索流程

### 2.1 有种子省份

1. 提取项目/iMA 中的名称、编号和年份；
2. 按 M6 建立地基、桩基、岩土、抗震、减隔震、装配式、既有建筑、材料与质量控制等标准族；
3. 在省级住建厅精确搜索编号，再到全国标准信息公共服务平台核对状态；
4. 从“代替/被代替/同时废止/复审”字段补全版本链；
5. 仅有正文或发布证据时保留 `pending`。

### 2.2 无种子或低覆盖省份

1. 先找省级住建厅“现行有效目录、废止目录、标准公告、标准定额”四类入口；
2. 用省级编号前缀反查全国平台，例如宁夏 `DB64`、青海 `DB63`；
3. 从现行目录按结构专业主题筛出候选，再沿“代替”字段反向补旧版；
4. 对没有整表目录的地区，使用后续官方文件中的规范性引用做发现证据，但状态保持待核；
5. 如果一个省只有少量记录，页面仍返回真实结果，同时在台账记录“低覆盖”，不得用无关交通、农业标准凑数。

## 3. 两个覆盖率必须分开

- **目录覆盖率**：已发现的结构相关标准数量/已知种子与权威目录中结构相关标准数量。
- **状态确认率**：已有现行、废止或替代权威证据的记录数量/已发现记录数量。

目录覆盖高不代表状态可信；状态确认率高也不代表目录齐全。青海本轮 4 条均有明确废止状态，但仍缺少可确认的现行结构类目录，因此属于“状态确认率高、现行目录覆盖低”。

## 4. 状态判定门槛

| 证据 | 可以得出的结论 | 不可以得出的结论 |
|---|---|---|
| 主管部门现行有效目录 | 现行 | 自动推断所有未列项目已废止 |
| 主管部门废止公告/废止目录 | 已废止、日期、替代关系（若载明） | 自行猜测替代标准 |
| 全国标准平台状态页 | 现行/废止及平台载明日期 | 覆盖未进入平台的全部 `DBJ/XJJ` |
| 主管部门发布公告或标准正文 | 已发布、编号、实施日 | 截至核查日仍现行 |
| 后续主管部门文件引用 | 后续仍被引用 | 确认现行 |
| 征求意见稿、采购公告、出版库 | 候选发现 | 正式状态结论 |

## 5. 本轮新增的低覆盖告警规则

1. 省级目录少于 5 条时，台账必须说明是“确实很少”还是“公开源不足”；
2. 只有非现行记录、没有现行记录时，不显示“该省无现行标准”，而显示“本轮未取得可确认的现行结构类记录”；
3. 超过一半记录为 `pending` 时，不把该省描述为“已完成判废”，只描述为“已建立候选目录”；
4. 官方网页出现后续引用但无状态表时，标签统一为“后续官网文件引用/现行目录待核”；
5. 征求意见稿中出现的标准编号只能用于发现，不能把征求意见稿自身收进正式标准清单；
6. 页面记录数不得作为质量 KPI，宁可少而可追溯，也不混入明显无关专业标准。

## 6. 本轮形成的结论

- 宁夏：有 2025 年自治区住建厅现行有效目录，可高置信建立现行项和三条旧版替代链。
- 新疆：2024 年复审目录与官网发布页适合建立候选目录，但复审结论未见公开，9 条均保留待核。
- 内蒙古：后续官方文件可证明若干标准仍被引用，但没有取得同等级现行总目录，4 条均保留待核。
- 青海：全国平台可明确确认 4 条旧标准已废止；本轮未取得可确认的现行结构类目录，不以交通类标准填充。
- 四川、西藏：省厅体系文件或全国平台可确认部分现行标准。
- 贵州、陕西、甘肃：种子目录已建立，但大量工程建设标准仍缺当前有效状态总表，保持待核。

## 7. 601 增量字段/API需求

- `coverage_state`：`normal / low_coverage / no_current_confirmed`；
- `coverage_basis`：种子目录、现行目录、废止目录、全国平台的数量统计；
- `discovery_evidence` 与 `status_evidence` 分离；
- `official_catalog_date`、`review_pending_since`；
- `status_confidence`：`confirmed / partial / candidate`；
- `replacement_effective_date`；
- `query_warning`：供③和 DeepSeek 输出“目录不全/状态待核”提示；
- API 返回 `coverage_summary`，不得把空数组直接解释为“无适用地方标准”。

网页发现结果仍只进入候选区。未经人工确认，不写入 601 正式库，也不作为 DeepSeek 的确定性规范结论。
