## 2. 天津重点区域测试

### TJ-01 滨海新区国标摘录

- 输入：确认地点“天津市 / 滨海新区”。
- 现有本地摘录预期：抗震参数 `8 度 / 0.20g / 第二组`。
- 证据：`source_id: SRC-20260917-003`，定位“天津市表／天津市／滨海新区行（Markdown第84行）”。
- 状态必须显示“待正式规范复核”，不得显示“正式库 / 可直接采用”。

### TJ-02 西青区差异

- 输入：确认地点“天津市 / 西青区”。
- 现有本地摘录预期：`7 度 / 0.15g / 第二组`。
- 证据：`source_id: SRC-20260917-003`，定位“天津市表／天津市／西青区行（Markdown第86行）”。
- 验收：不能因同属天津而复用滨海新区的值。

### TJ-03 风雪站点与行政区分离

- 输入：滨海新区，风雪候选同时出现天津市站与塘沽站。
- 本地摘录：天津市站 `0.50 / 0.40 / Ⅱ`；塘沽站 `0.55 / 0.35 / Ⅱ`，均为待正式复核。
- 验收：系统显示“气象站匹配”是独立决策，不按区县名称自动挑站。

### TJ-04 地标与专项冲突夹具

- 夹具：同一参数有“国标候选值 A”“天津地方候选值 B”“专项候选值 C”，范围重叠且值不同。
- 验收：三轨并列、同一 `conflict_id`、按钮禁用；不按“更严格”自动选 C。

### TJ-05 废止/未实施状态夹具

- `publication_date=2026-08-01, implementation_date=2026-12-01`，基准日 2026-09-25 → 未实施。
- `repeal_date=2026-09-01`，基准日 2026-09-25 → 已废止。
- 两者均显示完整日期原因并禁止送①。

## 3. 云南项目测试

### YN-01 昆明盘龙区

- 输入：云南省 / 昆明市 / 盘龙区。
- 本地摘录预期：`8 度 / 0.20g / 第三组`。
- 证据：`source_id: SRC-20260917-003`，定位“云南省表／昆明市／盘龙区行（Markdown第2469行）”。
- 状态：待正式规范复核。

### YN-02 昆明风雪候选

- 本地摘录预期：昆明市站 `风压 0.30 / 雪压 0.30 / Ⅲ区`。
- 证据：`source_id: SRC-20260917-002`，定位“云南表／昆明市行（Markdown第796行）”。
- 验收：风雪站点证据与盘龙区地震证据分开显示。

### YN-03 项目资料对照

- 将①当前值与上述候选并排；一致时显示“多来源一致”，但仍保留两个 `source_id`，不得合并成无来源单值。
- 若①被人工改成其他值，显示 `project_mismatch`，只允许用户在①决定，不回写 601。

### YN-04 未检索到地方规定

- 601 返回空的 local/special 结果。
- 页面必须显示“601 未检索到匹配记录，不等于不存在”，并提供“联网发现候选”入口。
- DeepSeek 不得回答“云南无地方特殊规定”。

## 4. 可信流程测试

| ID | 场景 | 预期 |
|---|---|---|
| TRUST-01 | 搜索结果摘要含精确数值 | 只建 discovered 候选，数值不得进入正式 claim |

| TRUST-03 | 正式正文、条款定位、哈希齐全 | 可提交人工复核，但仍非自动批准 |

## 7. 自动化验收门槛

- 地点解析用例通过率 100%；`ambiguous / unresolved` 零自动写回。
- 每个可见规范 claim 的 `source_id` 与 `locator` 完整率 100%。
- `review_status != approved_formal` 或 `effective_status != effective` 的 `adoptable` 必须为 false。
- 任一开放冲突存在时，对应参数组的批量采用按钮必须禁用。
- ①参数变更事件 100% 有 603 决定记录；601 不因项目采用而变化。
- 同输入、同 `as_of_date`、同 601 版本的返回顺序与状态确定性 100%。
- 回归现有 `cdp_kn`、`cdp_link`、角色/状态、导出一致性；章节、表格、OCR 输入与既有输出数量不得静默减少。

## 8. 当前原型可执行测试

运行：

```powershell
node .\prototype\tests.mjs
node .\prototype\online-tests.mjs
```

`tests.mjs` 当前覆盖 5 个地点解析用例：临港歧义、天津临港待确认、天津多候选、滨海新区精确解析、云南盘龙区精确解析。`online-tests.mjs` 覆盖公告实施/废止解析、标准改名改号、逐行查询拆分和云南现行目录拆分。联网适配器还需通过运行中的 `/api/discover` 做天津、云南实源冒烟测试；解析单测与在线可达性必须分开报告。
