# 用钢量模块版式修订核对记录

核对对象：

- 原始概念图：`steel-material-ledger-concept.png`
- 设计人员桌面截图：`qa/layout-revision-designer-native.png`（1672 × 941）
- 专业负责人截图：`qa/layout-revision-reviewer.png`
- 窄屏截图：`qa/layout-revision-mobile.png`（390 × 844）

## 核对点

| 核对点 | 修订要求 | 浏览器实现与处理 |
|---|---|---|
| 工作台集成 | 仍为既有工作台中的模块 | 保留顶栏、主导航、左侧说明和 ⑤ 用钢量统计入口，仅修改独立 Demo 模块文件 |
| 设计人员范围 | 一人一个单体，只显示单体 A | 设计人员端项目区标题改为“我的单体 · 单体 A”，未渲染 B/C/D |
| 材料展示 | 混凝土、钢筋、基础横排可见，分别下拉 | 三个披露控件按 01/02/03 横排；展开状态相互独立，表格按同一顺序纵向排列 |
| 负责人范围 | 不展示原始文件和来源校验 | 负责人端没有文件名、source_id、来源准确性提示，只显示总表和三类工程量表 |
| 图表替换 | 删除单体饼图，改为 A–D 总表 | 总表列为混凝土单方量、钢筋用量、基础混凝土总量；A 为当前样本，B–D 明确标为演示数据 |
| 数据清理 | 删除个数、空值、无关标识 | 当前表格只保留有效工程量字段；基础表继续过滤零值，未出现“个数”和 source_id |
| 响应式 | 窄屏可滚动查看 | 390 × 844 下披露控件纵向排列，宽表在自身容器内横向滚动，不挤压页面 |

## 交互验证

- 收起“混凝土”后，“钢筋”和“基础”仍保持展开。
- 专业负责人端同时展开单体 A 和单体 B 时，单体 A 不会自动关闭。
- 设计人员 / 专业负责人切换时，顶部角色选择同步更新。
- JavaScript 通过 `node --check`。

## 与原概念图的有意差异

原概念图中的材料 Tab、单体饼图、来源编号和负责人来源核验区均按本轮用户要求删除；这些是需求更新导致的有意差异。保留的视觉基线包括工作台外壳、蓝灰配色、表格密度、边框层级和信息层次。
