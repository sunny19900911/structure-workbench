# 用钢量业务口径与计算规则

## 1. 统计对象与边界

统计层级为“项目 → 单体 → 版本 → 空间范围/构件分类 → 材料”。每次填报必须绑定项目、单体、设计阶段、数据截止日期和来源。

### 1.1 材料范围

| `material_scope` | 名称 | 默认纳入 | 默认不纳入 |
|---|---|---|---|
| `rebar` | 普通钢筋 | 基础、主体、二次结构中计入结构专业工程量的钢筋 | 施工损耗、措施筋的临时增量、预埋件、幕墙/机电支吊架 |
| `prestress` | 预应力钢材 | 钢绞线、预应力筋 | 锚具质量，除非另设明细项 |
| `structural_steel` | 型钢/钢结构 | 钢梁、钢柱、钢支撑、型钢混凝土中的型钢 | 钢筋、预埋件、围护龙骨 |
| `embedded_steel` | 预埋及连接钢材 | 预埋件、连接板、栓钉等 | 主体型钢、普通钢筋 |

默认管理指标为“普通钢筋单方”。各材料分别显示；只有在 `conversion_rule_id` 已配置、规则版本已冻结且专业负责人复核后，才允许展示“折算总用钢量”，并同时保留原始分项。

### 1.2 空间范围

- `above_ground`：室外设计地坪以上的楼层构件；转换层按其所在楼层归属。
- `below_ground`：地下室及室外设计地坪以下楼层构件。
- `foundation`：基础、承台、筏板、桩帽、基础梁。默认计入地下范围，同时在构件维度单独可见，避免重复汇总。
- 多塔带大底盘项目：塔楼与底盘应有明确分摊方法。无法可靠分摊时，只允许项目级汇总，不生成塔楼级比较结论。

### 1.3 面积口径

必须同时记录面积数值和口径代码：

- `gfa_total_m2`：本版本用于单方计算的总建筑面积。
- `gfa_above_m2`、`gfa_below_m2`：地上、地下建筑面积。
- `area_basis_code`：面积口径来源，如 `planning_permit`、`architect_schedule`、`model_calculated`。
- `area_source_id`：面积来源。无法定位来源时标记“待核实”，不得进入正式比较。

同一比较批次只使用同一面积口径族。设计阶段发生面积变化时必须新建版本，不覆盖旧值。

## 2. 构件分类

一级分类互斥且完备；明细不得同时进入两个一级分类。

| 一级代码 | 一级分类 | 二级示例 |
|---|---|---|
| `FND` | 基础 | 桩、承台、筏板、独立基础、基础梁 |
| `VER` | 竖向构件 | 柱、剪力墙、边缘构件 |
| `BEAM` | 梁类 | 框架梁、次梁、连梁 |
| `SLAB` | 板类 | 楼板、屋面板、楼梯板 |
| `SEC` | 次要结构 | 楼梯、雨棚、设备基础、二次结构 |
| `OTH` | 其他 | 经负责人定义且无法归入上述类别的项目 |

`OTH` 占总量超过 5% 时触发分类质量预警；超过 10% 时不得进入构件构成比较，直至补充说明或重新分类。

### 2.1 当前钢筋原表归并规则

`主楼钢筋用量.xls` 的页面与清洗输出按四类构件展示：

- 梁 = 梁 + 墙梁；
- 柱 = 柱；
- 墙 = 墙身 + 边缘构件；
- 板 = 板。

直径列只作为来源分项和校验依据，不在管理表中逐列展示；零值直径列、无业务含义的“个数”列不进入页面。来源合计与直径分项求和超过容差时，统计值取分项求和，并同时保留来源合计、差异值和负责人复核状态。

基础混凝土表只保留非零构件体积，按以下口径显示：

```text
基础混凝土合计(m³) = Σ非零基础构件混凝土量
基础单方(m³/m²) = 基础混凝土合计 ÷ 基础面积
构件占比(%) = 指定基础构件混凝土量 ÷ 基础混凝土合计 × 100%
```

## 3. 核心计算公式

以下公式以某一 `material_scope` 为单位计算，不跨材料相加。

```text
总用量(t) = Σ构件明细净用量(t)
地上用量(t) = Σspace_scope = above_ground 的净用量(t)
地下用量(t) = Σspace_scope ∈ {below_ground, foundation} 的净用量(t)
总单方(kg/m²) = 总用量(t) × 1000 ÷ gfa_total_m2
地上单方(kg/m²) = 地上用量(t) × 1000 ÷ gfa_above_m2
地下单方(kg/m²) = 地下用量(t) × 1000 ÷ gfa_below_m2
构件占比(%) = 指定构件用量 ÷ 同材料总用量 × 100%
地下比例(%) = gfa_below_m2 ÷ gfa_total_m2 × 100%
```

显示精度：质量保留 0.1 t，单方保留 0.1 kg/m²，占比保留 0.1%。判断与比较使用未四舍五入值。

### 3.1 平衡校验

```text
abs(总量 - 地上量 - 地下量) ≤ max(0.1 t, 总量 × 0.2%)
abs(总量 - Σ构件一级分类量) ≤ max(0.1 t, 总量 × 0.2%)
abs(gfa_total - gfa_above - gfa_below) ≤ max(1 m², gfa_total × 0.1%)
```

超出容差为阻断错误；容差内差值保留为 `rounding_adjustment`，不得静默抹平。

## 4. 比较口径

### 4.1 强制同类条件

下列任一项缺失时，状态为 `not_comparable`：

- 建筑使用性质/主要功能；
- 主体结构体系；
- 设计阶段；
- 地上层数、地下层数、建筑高度；
- 抗震设防烈度、设防类别；
- 地区（省/市，或已配置的区域组）；
- 面积口径及其来源；
- 材料范围和构件分类规则版本；
- 专业负责人复核状态。

### 4.2 可比等级

| 等级 | 条件 | 页面行为 |
|---|---|---|
| A 直接可比 | 功能、体系、阶段、设防类别、地区组一致；层数/高度在同一分箱；面积及材料口径一致 | 展示中位数、P25–P75、样本量和差异原因 |
| B 条件可比 | 仅一个非安全关键条件邻近，如相邻高度分箱；经规则明确允许 | 展示区间，但标“条件可比”，必须展开差异说明 |
| C 仅供参考 | 样本较少或两项条件邻近 | 仅展示分布，不输出“偏高/偏低”判断 |
| D 不可比 | 关键字段缺失、规则/版本不一致或复核未通过 | 不进入区间，列明原因与补数负责人 |

建议分箱以配置表维护，不写死在前端：地上层数（1–6、7–11、12–18、19–26、27–33、34+）、高度（≤24 m、24–50 m、50–80 m、80–100 m、100–150 m、150 m+）仅作为初始建议，正式值由专业负责人批准。

### 4.3 样本量与稳健统计

- `n ≥ 8`：可展示中位数、P25–P75，并按规则生成“低于区间/位于区间/高于区间”。
- `5 ≤ n < 8`：只展示最小–最大和中位数，标记“小样本”，不生成优劣判断。
- `n < 5`：不生成统计区间，只列相似案例供人工查看。
- 异常点不得自动删除。经确认的录入错误进入新版本修正；真实极端项目继续保留，并在比较快照中记录纳入/排除原因。
- 可采用 `1.5 × IQR` 或稳健 Z 分数作为“复核信号”，不得直接作为质量结论。

### 4.4 归一化表达

默认主指标是“相对同类中位数比值”，仅作解释：

```text
peer_ratio = 当前单方 ÷ 同类样本中位数
```

当同类样本 `n ≥ 30` 且模型通过负责人批准，可增加高度、地下比例等连续变量的稳健回归残差；模型必须版本化并展示训练样本、误差区间和适用范围。回归结果为辅助说明，不能覆盖原始单方与同类区间。

## 5. 统计状态

一次提交依次经过：

`draft → validation_failed / ready_for_review → under_review → approved / returned → superseded`

只有 `approved` 且未被 `superseded` 的版本进入正式汇总。管理总览可以单独显示未完成或待复核数量，但不得将草稿数值混入正式均值。

## 6. 结论与来源

每条页面结论均返回：

- `claim_type`：`原文事实`、`作者观点`、`我的观点`、`AI推断` 之一；
- `source_ids[]`：来源文件、填报记录、面积表、模型导出或复核记录；
- `calculation_rule_version`：计算规则版本；
- `cohort_snapshot_id`：比较样本快照；
- `generated_at`：生成时间。

无法定位来源时结论显示“待核实”，不进入正式统计或优秀基准。
