## 核心原则

1. **先校验，再统计；先满足可比条件，再比较。** 面积口径、材料范围或版本不完整时，允许保存草稿，但不进入横向区间。
2. **钢筋与型钢/钢结构分开统计。** 除非明确选择经负责人确认的折算规则，否则不得合并为一个“总用钢量”。
3. **比较采用区间和原因解释，不输出粗暴名次。** 默认展示同类样本中位数、P25–P75 和样本量。
4. **低值不等于优秀。** “优秀参考案例”必须满足完整性、复核、阶段稳定性及安全质量前提，并由专业负责人确认。
5. **所有结论可追溯。** 原始填报、导入文件、修订、复核、比较快照和异常处置均保留 `source_id` 或关联来源列表。
6. **仅作管理辅助。** 指标用于项目复盘、方案优化、资源协调和抽查，不直接作为个人绩效排名依据。

## Demo 运行

在 `web-demo` 根目录启动现有 Vite 服务：

```powershell
cd "C:\Users\mj528\Documents\004 工作\web-demo"
npm run dev
```

然后按 Vite 终端显示的端口访问（默认通常为 `5173`；若端口被占用会自动改为 `5174` 等）：

```text
http://127.0.0.1:<VITE端口>/design/parallel-tasks/04-steel-dashboard/prototype/workbuddy-integrated-studio-steel-demo.html
```

Demo 的设计人员视图可读取用户指定的 TXT / XLSX。最新 `主楼钢筋用量.xls` 已识别 13 层并按梁、柱、墙、板重新汇总；105 目录中的旧柱钢筋样本仍视为不完整资料，不进入完整单体比较。管理视图其余单体为 `DEMO-SRC-*` 演示构造数据。

材料台账改版已支持按项目展开单体 A/B，并在每个单体内切换上部混凝土、钢筋、基础混凝土三张表。钢筋按梁、柱、墙、板归并；基础表删除“个数”和零值列，补充基础面积、合计和单方；负责人视图直接复用同一份材料明细进行复核。

正式接入前必须先落实 `04-API与持久化需求.md` 中的版本、权限和审计要求，并由主任务确认后再修改核心工作台。
