# 字段字典与校验规则

## 1. 导入文件关系

- `单体用钢量汇总导入模板.csv`：每行代表“一个单体 + 一个版本 + 一种材料范围”。
- `构件用钢量明细导入模板.csv`：每行代表上述版本中的一个空间范围和构件分类明细。
- 两表通过 `submission_external_id + building_external_id + material_scope` 关联。
- CSV 必须为 UTF-8；首行字段名不可改；空值留空，不使用 `/`、`无`、`—` 代替。

## 2. 汇总模板字段

| 字段 | 类型/单位 | 必填 | 说明与规则 |
|---|---|---:|---|
| `submission_external_id` | string | 是 | 导入方生成的幂等键；同一来源内唯一 |
| `project_external_id` | string | 是 | 项目外部编号，不以项目名称关联 |
| `building_external_id` | string | 是 | 单体外部编号；项目内唯一 |
| `building_name` | string | 是 | 单体名称，1–100 字符 |
| `building_use_code` | enum | 是 | 住宅、办公、商业、学校、医院、工业等受控字典 |
| `region_code` | string | 是 | 行政区或批准的区域组代码 |
| `structure_system_code` | enum | 是 | 框架、框架-剪力墙、剪力墙、筒体、钢结构等 |
| `design_stage` | enum | 是 | `scheme` / `preliminary` / `construction_doc` / `as_built` |
| `above_floors` | integer | 是 | 0–200，设备夹层按项目楼层口径说明 |
| `below_floors` | integer | 是 | 0–20 |
| `building_height_m` | decimal | 是 | >0 且 ≤1000；同一版本唯一口径 |
| `fortification_intensity` | enum | 是 | 6/7/8/9 度或项目受控值 |
| `seismic_category` | enum | 是 | 标准设防、重点设防、特殊设防、适度设防 |
| `gfa_total_m2` | decimal | 是 | >0；与地上/地下面积通过平衡校验 |
| `gfa_above_m2` | decimal | 是 | ≥0 |
| `gfa_below_m2` | decimal | 是 | ≥0 |
| `area_basis_code` | enum | 是 | 规划证、建筑面积表、模型计算等 |
| `area_source_id` | string | 是 | 来源登记中的 `source_id`；无来源则状态待核实 |
| `material_scope` | enum | 是 | `rebar` / `prestress` / `structural_steel` / `embedded_steel` |
| `total_mass_t` | decimal | 是 | ≥0；与空间和构件明细平衡 |
| `above_mass_t` | decimal | 是 | ≥0 |
| `below_mass_t` | decimal | 是 | ≥0，包含基础时须与 `scope_rule_version` 一致 |
| `quantity_source_id` | string | 是 | 工程量表、模型导出或经确认填报的来源标识 |
| `data_cutoff_date` | date | 是 | `YYYY-MM-DD`，不能晚于提交时间 |
| `source_file_name` | string | 否 | 仅存原文件名；文件本体由主任务文件服务管理 |
| `source_file_hash` | string | 否 | SHA-256，用于去重和追踪，不在前端计算 |
| `scope_rule_version` | string | 是 | 材料、空间和构件口径规则版本 |
| `notes` | string | 否 | 最多 1000 字；说明特殊体系、分摊或范围差异 |
| `prepared_by` | user_id | 是 | 填报人，不接受自由文本姓名作为唯一身份 |

## 3. 构件明细字段

| 字段 | 类型/单位 | 必填 | 说明与规则 |
|---|---|---:|---|
| `submission_external_id` | string | 是 | 关联汇总版本 |
| `building_external_id` | string | 是 | 关联单体 |
| `material_scope` | enum | 是 | 必须与汇总表一致 |
| `space_scope` | enum | 是 | `above_ground` / `below_ground` / `foundation` |
| `floor_from`、`floor_to` | string | 否 | 可为 B2、1F、RF；采用受控解析规则 |
| `component_l1_code` | enum | 是 | `FND` / `VER` / `BEAM` / `SLAB` / `SEC` / `OTH` |
| `component_l2_code` | enum | 否 | 二级构件字典代码 |
| `mass_t` | decimal | 是 | ≥0 |
| `source_total_t` | decimal | 否 | 来源表“合计”列原值；即使冲突也不得覆盖 |
| `recomputed_total_t` | decimal | 否 | 由直径或分项列重新求和的值 |
| `total_conflict` | boolean | 是 | 来源合计与分项求和是否超过容差 |
| `conflict_resolution` | enum | 条件必填 | `pending_review` / `use_source_total` / `use_recomputed_total` |
| `calculation_method` | enum | 是 | `model_export` / `quantity_takeoff` / `manual` / `estimated` |
| `quantity_source_id` | string | 是 | 明细来源 `source_id` |
| `notes` | string | 条件必填 | `OTH`、估算或分摊数据必须填写原因 |

## 4. 校验规则分级

### 4.1 阻断错误 `error`

- 唯一键冲突但内容不同；
- 必填字段缺失或枚举不合法；
- 面积、质量为负数；
- 总量/空间/构件平衡超过容差；
- 同一提交混用多个 `scope_rule_version`；
- 来源不存在、无权限或已失效；
- 已审批版本被原地覆盖；
- 地下单方分母为 0 但地下用量大于 0。

### 4.2 需确认预警 `warning`

- `OTH` 超过 5%；
- 手工或估算数据占比超过 10%；
- 面积较上一版本变化超过 3%；
- 总量较上一版本变化超过 8%；
- 统计值超出同类 P25–P75，或触发 `1.5 × IQR`；
- 数据截止日距当前超过项目阶段允许时限；
- 条件可比但存在一个分箱差异。

预警不直接否决提交，但必须有 `reason_code + comment + owner_user_id`；统计异常由专业负责人决定是否接受。

### 4.3 信息提示 `info`

- 新版本替代旧版本；
- 样本量不足，不能生成判断；
- 本批次没有可用的优秀参考案例；
- 过滤条件导致部分单体不可比。

## 5. 版本与导入行为

1. 先执行“预检”，返回逐行错误、预警和预计新增/更新数，不写入正式版本。
2. 用户确认后创建不可变 `submission_version`；若全部相同则按幂等键返回已有版本。
3. 修正任何已提交数值都创建新版本，记录 `supersedes_submission_id` 和差异摘要。
4. 审批只对冻结版本生效；审批后原版本只读。
5. 批量导入的失败策略默认为整批原子提交；可选“仅保存草稿行”，但不得部分进入正式汇总。

## 6. 数据质量分项（不合并为绩效分数）

页面可以分别显示：

- 完整性：必填及条件必填字段齐全；
- 一致性：汇总、空间、构件平衡通过；
- 时效性：截止日期满足阶段要求；
- 可追溯性：面积和用量来源可打开；
- 复核状态：负责人通过/退回/待审。

不得把这些维度压缩成不透明的单一“人员得分”。
