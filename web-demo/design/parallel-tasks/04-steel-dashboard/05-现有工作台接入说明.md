# 现有工作台接入说明

## 1. 接入结论

本模块不是独立网页。正式接入对象是最新版完整工作台：

- 生产工作台：`web-demo/workbuddy-integrated-studio.html`
- 接入位置：现有第⑤模块“用钢量统计”
- 复用能力：工作台现有导航、角色切换、阶段容器，以及 `st*` 系列 TXT / XLSX 解析与统计函数
- 管理联动：经负责人复核并冻结的单体版本，向现有第⑥模块“全院总览”提供只读汇总快照

当前 Demo 是上述生产工作台的完整副本，仅在副本中加载 `steel-demo-module.css` 和 `steel-demo-module.js`。未修改生产工作台文件，未连接或重建生产数据库。

## 2. 业务来源与优先级

接入时按以下优先级执行：

1. 以最新版 `web-demo/workbuddy-integrated-studio.html` 作为页面壳、导航与角色体系。
2. 以 `105-用钢量统计` 已核对样本和《00-输出格式标准》v1.1 作为解析、指标与输出规则来源。
3. 以 `100-任务拆解` 作为工作台定位和管理流程参考。
4. 对历史页面中的规则，只复用与最新版输出标准不冲突的部分；已取消的“标段分摊”不进入新流程。

## 3. 页面内模块结构

第⑤模块内部设置三个角色视图，共用同一份单体版本数据：

| 角色视图 | 主要任务 | 可写范围 |
|---|---|---|
| 设计人员填报 | 上传 TXT / XLSX、核对解析结果、补全项目条件、提交复核 | 草稿与本人提交版本 |
| 专业负责人复核 | 检查来源、统计边界、版本差异、异常原因并通过或退回 | 复核状态、意见与冻结动作 |
| 管理总览 | 查看覆盖率、同类样本区间、异常队列和项目趋势 | 原则上只读；不得改写原始数据 |

## 4. 正式接入最小改动方案

待用户确认后，正式接入建议保持小而可回退：

1. 将 Demo 中的第⑤模块增强样式与交互合并到工作台现有资源体系，不复制第二套工作台。
2. 保留现有 `st*` 解析器为前端预检；原始文件、解析结果、版本与复核记录通过主任务提供的 API 持久化。
3. 将当前前端演示常量替换为 API 数据；所有指标返回 `source_id`、口径版本和复核状态。
4. 只有 `review_status=approved` 且 `comparability_status=comparable` 的冻结版本才进入正式同类区间。
5. 第⑥模块只读取批准快照，不直接读取设计人员草稿，避免管理视图随草稿变化。

## 5. 与主任务的数据接口边界

本任务不建库，只向主任务提出以下持久化能力：

- 单体基本条件、统计边界和面积口径；
- 原始文件清单、文件哈希、解析结果和 `source_id`；
- 用量版本、版本差异、原因备注和负责人复核记录；
- 可比性判定、同类样本条件、区间快照和基准案例审批；
- 角色权限、操作审计和管理汇总快照。

详细字段与 API 见 `04-API与持久化需求.md`。

## 6. 当前样本的限制

`105-用钢量统计` 当前可核对的钢筋样本仅覆盖第 1 自然层柱钢筋，不代表完整单体钢筋量。因此 Demo 可展示读取、计算和复核流程，但该样本必须标为“不可比”，不能用于项目优劣、个人绩效或全院排名。
