# 接入现有工作台⑦方案

## 1. 接入结论

唯一目标是现有 `workbuddy-integrated-studio.html` 的 `<section id="stage7">`。本任务不创建独立网站，不增加第二套导航，不在⑦复制一套可编辑参数。

当前⑦原占位模块已在用户批准后完成最小补丁：替换 `#stage7` 内部占位内容，并移除既有 `CARDS` 中 `c7` 的 `todo:true`；保留 `#tab7`、`#toc7`、`#stage7`、①—⑧顺序、角色、阶段和状态机。

## 2. 模块接口关系

| 对接方 | 输入⑦ | ⑦输出/反馈 |
|---|---|---|
| ①统一措施 | 项目参数、构造措施、结构特征、版本 | 缺失参数和影响范围；参数修改仍回①/603 |
| ②扩初说明 | 工程概况、单体、基础方案、已审文字 | 一致性问题，不复制文字真源 |
| ③地方规范 | 已确认规范清单、适用地域、有效性 | 未确认/失效引用的阻断项 |
| ④反校核 | 模型/图纸/网页/说明的差异 | 说明侧差异项、快照ID |
| 603项目库 | 参数快照、项目决定、人工覆盖、审签、输出 | 写入项目决定与正式快照 |
| 604条款库 | 母版、条款、规则、来源 | 只读消费，不写项目值 |

## 6. API契约草案

| 方法 | API | 数据归属 |
|---|---|---|
| GET | `/api/projects/{project_id}/profile?version=` | 603 |
| GET | `/api/general-notes/masters/{master_id}?version=` | 604 |
| GET | `/api/general-notes/rulesets/{version}` | 604 |
| GET/POST | `/api/projects/{project_id}/general-notes/decisions` | 603 |
| POST | `/api/projects/{project_id}/general-notes/validate` | 校核服务，结果回603 |
| POST | `/api/projects/{project_id}/general-notes/outputs` | 603输出快照 |
| POST | `/api/projects/{project_id}/general-notes/export/docx` | 以快照ID导出 |
| GET | `/api/norms/confirmed?project_id=` | ③/601 |
| GET | `/api/projects/{project_id}/review-diffs` | ④ |

所有写接口需乐观锁/版本号和审计身份；导出接口只接受已锁定 `output_snapshot_id`。

## 7. 网页/Word同源契约

`output_snapshot` 至少包含：`project_profile_version`、`master_version`、`feature_ruleset_version`、`cleaning_ruleset_version`、`decision_version`、`visible_clause_ids`、`numbering_map`、`resolved_placeholders`、`source_manifest`、`hash`。

网页预览和Word导出不得各自重新求值。任何源版本变化都生成新快照并令旧审签失效。
