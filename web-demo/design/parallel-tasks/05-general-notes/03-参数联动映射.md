# 参数联动映射

机器可读版本见 `03-参数联动映射.json`。核心原则：⑦只读①/②/③/④和603的版本化快照，不创建第二套可编辑参数。

## 1. 数据流

| 来源 | ⑦的使用方式 | 写回边界 |
|---|---|---|
| ①统一措施 | 读取工程参数、结构参数、建筑特征和统一做法 | 参数修改回①/603；⑦只显示来源、版本和影响 |
| ②扩初说明 | 读取工程概况、单体、基础和已审说明 | 发现冲突形成问题项，不在⑦静默覆盖 |
| ③地方规范 | 只引用已确认适用规范及有效性状态 | 未确认/失效规范阻断审签 |
| ④反校核 | 读取网页、模型、图纸、总说明之间的差异 | ⑦不直接修正④，只生成关联问题项 |
| 603项目库 | 保存项目参数版本、人工决定、覆盖理由、锁定快照和正式输出 | 唯一项目真源 |
| 604条款库 | 提供母版、稳定 `clause_id`、规则和公共来源 | 不保存项目取值和人工决定 |

## 2. 已有参数映射摘要

| 现有键/数据集 | 总说明目标 | 处理 |
|---|---|---|
| `project_name/project_code/discipline` | 封面、总则、工程概况 | 直接注入，缺失阻断 |
| `intensity/pga/eq_group/site_class/tg/alpha_max` | 抗震设防和计算参数表 | 同源显示；与③、④交叉检查 |
| `wind/snow/snow_zone/wind_shape/wind_rough` | 荷载章节 | 直接注入，单位由字段schema固定 |
| `temp_low/temp_high/frost` | 温度、冻土/施工条款 | 条件注入 |
| `seismic_cat/safety/normal_use/fire/waterproof` | 分类等级和耐久/防护 | 直接注入；涉及责任判断的空值阻断 |
| `foundation/pile/anti_float/water_depth/foundation_note` | 地基基础、桩基、抗浮 | 参数化并驱动特征建议；自由文本不驱动自动删除 |
| `struct_sys/seismic_up/iso_reduce` | 结构体系、抗震等级、减隔震 | 直接注入；`iso_reduce`不能替代 `has_iso` |
| `damping/period_reduce/fixed_end/ecc_ratio/bidir_eq/vert_eq/skew_angle/modal_combo/stiff_amp/mass_participation` | 计算分析章节 | 从①/计算摘要注入 |
| `g_frame`等构造键 | 混凝土构造条款 | 注入经审查统一措施 |
| `bldg_units` | 工程概况/单体表 | 使用稳定单体ID生成表格 |
| `geo_soil/geo_bore` | 地勘、持力层/地下水引用 | 仅引用已确认记录和source_id |
| `yjk_summary` | 计算程序、关键指标 | 标注软件版本、模型版本和快照时间 |

## 3. 已接入①的共享特征字段

主入口①“项目类型与专项特征”现已提供18个三态键：`has_concrete`、`has_steel`、`has_masonry`、`has_green_building`、`has_precast`、`has_iso`、`has_damp`、`has_health_monitoring`、`has_special_design_scope`、`has_existing`、`has_basement`、`has_pile`、`has_slope`、`has_human_def`、`has_superlong`、`has_posttension`、`has_recycled_concrete`、`has_ground_treatment`。⑦只读取①当前页面快照，不设置局部副本。

当前阶段这些值仍是页面内的 `local-live` 草案参数；正式接入时必须由①读写603版本化项目档案，⑦只读取同一版本并记录 `profile_version`。不得把当前页面默认值当作已批准的603项目事实。

仍待迁入/补齐：`has_longspan`、`has_join`、`has_convert`、`has_superhigh`，以及 `subitem_code/name`、`floor_above/below`、`struct_height`、`elev_diff`、`defense_grade`、`ground_elev`、`water_anti/water_compress`、`soil_thickness`、`basement_floors`、`fixed_end_floor`、`podium_floors`、`transfer_floor` 等字段。

## 4. 新增建议

| 建议键 | 类型 | 用途 | 风险级别 |
|---|---|---|---|
| `foundation_type` | enum/按单体 | natural / treatment / composite / pile / mixed | 高；未知时逐项确认 |
| `has_existing`等18个三态键 | tri-state | 已在①提供编辑入口；待持久化到603 | 中至高 |
| `design_life/environment_exposure` | enum/按单体或构件组 | 耐久性条款 | 高 |
| `foundation_designs` | array | 持力层、承载力、桩型、参数、来源 | 高 |
| `approved_norm_ids` | array | ③确认后的规范引用 | 高 |

所有 `has_*` 使用 `true / false / unknown`，不得把缺失值解释为 `false`。
