# 昆明重难点联动

使用者：小香金猪。需求来源：`USER-20261001-KUNMING-DECISIONS`（原文事实）。

①填写地点、烈度、体系 → ⑩读取当前单体已确认资料 → 按国家／云南／昆明规则生成判断 → 负责人确认后供①②⑪引用。输入或项目规范状态改变，原决定保留并转为待复核。

## 本次范围

- 七个专题：设防烈度、抗震等级、绿色建筑、装配式、性能目标、减震、隔震。
- 每项显示依据、适用条件、判断步骤、缺项及落实要求。补充条件写入原项目 `intake` 分区，使用既有版本冲突保护；没有另建参数库。
- 规则文件：`regional-decision-guide.js`，版本 `KM-20261001-1`。普通混凝土等级表仅提供候选；不生成模型验算通过结论。
- 地点只用于匹配规则。不得从“经开区”推定烈度、场地类别或其他工程参数。国家与省级隔减震条件分别判断；20%建造比例不等同于装配式建筑评价认定。
- 规范依据为原文事实的摘要；条件匹配结果为 AI 推断；人工采用后为负责人观点。未核项目规划条件、更高地方要求和特殊体系继续列为待核。
