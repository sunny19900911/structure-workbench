# 工程办公成果初版

使用者：小香金猪。source_id: USER-OFFICE-WORKFLOW-20261108（原文事实）。

院内流程组织项目资料和采用参数，生成一组实际 DOCX、PPTX、XLSX；页面和 MCP 编辑同一文件。界面只保留生成、打开、编辑、保存、下载。

| 内容 | 实现 |
|---|---|
| Word | SuperDoc 1.47.2：文字、字体字号、段落、表格、图片、撤销重做 |
| Excel | 当前参数/单体/扩初表格生成工作簿；工作表切换、单元格及公式输入，原生包保存 |
| PPT | 复用院内汇报模板生成；普通文字框改写、对象位置修改，原生包保存 |
| 文件 | 项目内不可变版本、同批次标识、来源参数版本；项目备份包含文件历史 |
| MCP | 同一业务命令；工程流程资源说明资料职责、编制顺序和院内规则 |

## 数据与生成

`office-workbench.js` 同步自动稿并保留人工章节，等待 PPT 采用目标参数快照，才建立三类成果。生成过程锁定当前输入；项目、单体、参数或正文变化时不报告整套生成成功。再次生成建立新文件，保留人工稿。

`server/office-document-store.mjs` 保存在 `WORKBENCH_PROJECT_STORE/<projectId>/.office-documents/<documentId>/versions/<revision>`。完整临时目录重命名提交元数据与二进制，历史不改写。`server/portable-projects.mjs` 备份并重映射新项目ID。

## 实际能力范围

- Word 的 A3 横向、双栏、表格合并、正文及图片需按测试文件往返核对。字体和分页不能据此称与任意 Microsoft Word 版本像素一致。真实模板隐藏在纵向合并续格内的重复文本会被编辑内核规范化；可见文本单独核对。
- Excel 修改不执行宏，公式缓存失效并标记重新计算；当前网页不承担 Excel 公式重算。
- PPT 当前绘制可编辑文字与图片，未完整绘制母版、主题和图表；这些原始文件部件保留。复杂字段、组图和不支持的修改不重建覆盖。
- 工程参数采用仍由统一措施负责。成果文件内的人工编辑不自动变成项目参数，也不表示结构验算完成。
