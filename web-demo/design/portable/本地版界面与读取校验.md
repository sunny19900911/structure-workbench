# 本地版界面与读取校验

依据：小香金猪要求免部署、各人独立存储、六模块精简、Word/Excel/PPT/PDF 多版本识别（`source_id: USER-20261030-PORTABLE`，原文事实）。

- 仅便携服务注入 `window.WORKBENCH_PORTABLE=true` 时启用。普通网页保持现有入口。可通过 `WORKBENCH_PORTABLE_VERSION` 显示软件版本。
- 保留统一措施、地方规范、扩初、PPT、用钢量、计算书；隐藏重难点、反校核入口和跳转。旧决定数据不删除，本地版不再将其自动编入措施和 PPT；扩初自身不规则措施库保留。
- “本机状态”展示安装软件的实际版本和组件能力；“识别文件格式”仅检查、不导入。文件创建软件元数据与安装软件版本分别表述。AI 配置为折叠选项，默认不影响离线基础功能。
- Excel 读取前校验实际容器/后缀/加密，再用本地 SheetJS 读取旧版 XLS、新版 XLSX、XLSM、XLSB 及模板文件。宏不执行。存在公式却没有保存计算结果时拒绝导入；读取的是文件已保存结果，不执行 Excel 重算。
- PDF 使用本地 PDF.js、CMap 和字体资源。便携模式不使用可能漏字的轻量解析兜底。逐页处理失败会终止；全部无文字时拒绝导入；部分无文字页保留页码提示，随 `intake.sources[].blocks.pdfReadReport` 保存，不进入生成正文。不将扫描图纸声明为已完整提取。
- 同一个 File 的预检复用成功结果，失败可重试。预检不修改原文件；加密、损坏、伪装后缀不能显示为成功。真实格式能力由 `server/document-format-api.mjs` 提供。

## 地方规范链接

`scripts/audit-portable-regulation-links.mjs` 对内置 306 条记录按 URL 去重进行公开网页核验；报告在 `data/portable-regulation-links.js`，本地运行详细记录在忽略的 `qa/portable-link-audit/`。

HTTP 成功且正文匹配具体规范编号（包含版本年份）才显示链接；没有具体编号的法规才按完整标题匹配。403、超时、404、未能匹配正文均隐藏链接，保留规范名称、编号、来源及原目录状态。链接核验不等同于规范有效性审查。真实断网时不提供外链；如登记了随包本地 PDF，优先展示本地资料。本轮没有将全套规范 PDF 打进包内。

## 本地前端资源

`portable-assets.json` 固定 SheetJS、PDF.js、Tesseract、WASM 和语言模型的下载位置，交付包须全部本地化；运行时不回退 CDN。现有 JSZip 和 PPT 模板继续随包提供。

## 验证

`node --test design/portable/portable-ui.test.mjs` 验证普通网页不受影响、格式预检、缓存/重试、加密及后缀拦截、规范链接策略、旧 Excel 读取与公式结果保护、PDF 不完整页提示、主页面脚本语法。

同时回归材料用量、规范目录、PDF 清单、资料导入和工作流。该验证不等同于所有 Office/WPS 实际版本和所有真实项目文件都已验收；发行包仍需在独立环境完成断网导入、重开和导出验证。
