# DeepSeek AI 接入说明

## 当前实现

一体化工作台顶部已增加“DeepSeek 助理”入口。AI 助理当前支持：

- 结合当前页面可见内容回答项目问题；
- 整理项目关键参数；
- 检查参数冲突、缺项和待确认事项；
- 给出需要进一步核对的规范类别和条文方向；
- 保留简短的当前会话上下文。

本阶段不自动上传原始建筑、地勘或计算文件。只有用户主动点击“发送”后，输入的问题以及勾选的当前页面上下文才会发送至 DeepSeek。

## 首次配置

1. 在 DeepSeek 开放平台创建 API Key；
2. 将 `web-demo/.env.example` 复制一份并命名为 `web-demo/.env.local`；
3. 打开 `.env.local`，填写：

```text
DEEPSEEK_API_KEY=你的_API_Key
DEEPSEEK_MODEL=deepseek-v4-pro
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

4. 双击工作目录中的 `启动Demo.cmd`；
5. 打开一体化工作台，点击顶部“DeepSeek 助理”；
6. 状态显示“已连接”后即可使用。

修改 `.env.local` 后必须重新启动 Demo。

## 安全设计

- API Key 只由本机 Vite 服务读取，不会进入浏览器页面；
- `.env.local` 已加入 `.gitignore`，不会被正常的 Git 提交收录；
- 浏览器只调用同源的 `/api/deepseek/*` 本地接口；
- 本地接口对输入长度、消息数量和响应时间进行了限制；
- AI 返回内容只作为工作建议，不会自动修改项目参数；
- AI 回复采用纯文本渲染，避免模型返回的 HTML 被网页直接执行。

## 数据边界

DeepSeek 是外部云端模型。使用正式项目资料前，应先确认公司的数据安全要求和允许上传的资料范围。

推荐先使用：

- 已脱敏的项目参数；
- 无个人信息的技术问题；
- 可以对外传输的规范摘要；
- 演示项目或历史公开项目。

不建议直接发送：

- 未经批准的完整项目文件；
- 涉密或敏感工程资料；
- 含个人信息、联系方式或账号信息的内容；
- 公司明确禁止上传外部平台的资料。

## 当前边界与后续方向

当前版本属于“受控对话 MVP”，重点验证模型接入、项目上下文和限定任务是否有用。尚未实现：

- 原始文件上传及长文档解析；
- 知识库检索增强（RAG）；
- 规范现行、废止状态的官方联网核查；
- AI 直接调用 Word、PPT、参数回写等工具；
- 全院账户、权限、费用和审计管理。

后续建议按照“资料检索 → 结构化参数 → 受控工具调用 → 审核后写回”的顺序扩展，不建议直接给予模型无审核的修改权限。
