# 不规则措施库接入

source_id: USER-20261002-IRREGULARITY-LIBRARY（用户指令，原文事实）。

- 六类固定：扭转、凹凸、楼板不连续、侧向刚度、竖向抗侧力构件不连续、楼层承载力突变。检查指定文件夹13份文件，在10份文件中整理34组分类摘录；不将穿层柱直接归为竖向抗侧力构件不连续。
- 数据为 `irregularity-library-data.js`；分类原文及来源见[措施分类与来源](措施分类与来源.md)，文件指纹见 `sources.json`。历史摘录为原文事实，默认通用整理稿为AI推断；各案例数值和目标保留原取值，不合并成当前工程参数。
- 缺项：第六类仅检索到判定记录（海南师范大学提取块628等），未找到独立应对措施。选择“是”时提供空白编辑区；不伪造历史措施。人大PPT以判定及设计注意事项为主，曲靖隔震报告未检索到对应六类措施正文。高层超限来源只作可选历史参考，不增加高层判定表。
- 规则表保持六项，原删除列改为是/否；初始“—”表示尚未选择。选择是时在10.2展开对应措施，可选择通用整理稿或历史原文并直接编辑；否隐藏措施，保留人工稿供再次启用。历史辅助选择和来源折叠不进入Word。
- `regularity.items` 按现有项目/单体扩初分区保存，含answer、choice、各版本drafts及source_ids；复用expectedRevision与签发锁定。原稿中删掉的规则行恢复为未判断，不自动判否；旧有/无结果继承。
- 验证：29项关联回归通过，构建通过（原有经典脚本及体积警告仍在）。5297隔离副本实测是/否显隐、人工编辑、历史版本选择与保存；原项目未预设实际不规则项。原生Word表格几何验证及Word渲染检查通过。测试文件在 `web-demo/qa/irregularity-library`。

在 `web-demo` 重建：先 `node design/irregularity-library/read-legacy.mjs`，再以工作区Python运行 `extract.py` 和 `build-library.py`。原始文件只读；全文中间件仅写入qa，入库摘录写入design和数据模块。
