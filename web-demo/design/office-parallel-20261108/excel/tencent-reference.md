## 实施原则（本项目设计选择）

以“页签 → 双层分组工具栏 → 地址/公式栏 → 表格 → 工作表/状态栏”为结构。高频编辑操作直接可见，菜单按开始、插入、数据、公式、视图组织；只展示本地已接线的操作。不伪造云端协作、会员、外部引用、图表/透视表等未实现能力。

字体、数字、边框、对齐、合并、条件格式与数据操作须修改真实 XLSX；页面与 MCP 仍调用同一命令和文件修订接口。打印明确为本地表格打印视图，不承诺完整 Excel 分页一致。复杂公式和复杂原包结构不支持时明确拒绝，不静默破坏原件。
