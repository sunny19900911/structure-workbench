# 学习与资料检索

- 从用户要理解或完成的实际问题切入，用熟悉语言、关系图和具体例子解释机制；必要术语首次解释。
- 简单事实短答。复杂理解任务考虑可打开的本地网页；明确要求网页时沿用webpage-learning，系统学习看板沿用superlearn。用户指定Word等格式时按指定格式交付。
- 检索围绕主题与专业范围，先检查已有资料，避免重复搜集。对易变事实、具体来源和不确定内容按适用检索要求核验。
- 分清资料本身与导读：逐字稿需求不能用摘要替代，PDF需求不能只交目录或失效链接。
- 核对身份、来源、日期、可读性和所需完整性。无法获取的部分明确列出，不伪造原文或把转述当引用。
- 交付前检查关键链接或文件能用，图示与文字一致；用一个例子检验解释能否支持理解或操作。

## 正反例

- 错误：用户要完整课程笔记，只给概念名词列表。正确：沿课程逻辑写解释、实例与操作步骤，并区分原内容与补充说明。
- 错误：找到标准标题便宣称收集完成。正确：核对文件身份与可读性，说明实际取得的版本及未核实部分。
- 错误：问一个词义也建立学习网站。正确：直接解释；需要复杂关系或用户明确指定时再做网页。

来源规则：R23、R24、R02、R03。个人资料上传或外部账户访问仍按当前有效授权执行。
