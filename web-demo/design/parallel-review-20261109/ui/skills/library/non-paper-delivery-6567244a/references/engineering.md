# 工程资料与成果联动

## 执行规则

- 先确定项目、单体、当前资料版本和模板。历史案例只能提供方法和写作参考，不能供应新项目数值或证明规范现行有效。
- 明确字段来源和采用值；缺项按项目约定留空或集中列出，不猜值。工程工具已有来源优先级与并发版本控制时按其流程执行。
- 参数变更检查依赖的正文、表格、PPT、计算书及导出物；保留人工修改，不以旧生成稿覆盖人工稿。
- 对照目标模板核对正文、表格和附件，保留指定章节、层级、图位与必要条目。删减根据适用性，不以篇幅短作为完整性指标。
- 原始资料与生成结果分区保存，区分原文事实、作者观点和推断；界面可用简短引用，底层来源仍可追溯。
- CAD输出沿用实际图层、线型、字体、标注和打印约定。计算结果和图纸是否符合要求必须依据实际检查，不能凭测试数量保证普遍正确。

## 验收选择

- 参数联动：在隔离副本或测试数据中更改一个相关源参数，核对实际依赖项；不要为验收改动真实工程采用值。
- 多项目功能：切换项目或单体，确认没有继承上一项目数值。
- 文档输出：对照模板逐项核查必需内容，按文档技能渲染检查；从正式入口打开实际输出。
- 来源检查：挑选关键结论回查具体原资料；CAD按本次改动检查真实显示或打印结果。

## 正反例

- 错误：新项目缺少高度，填入历史案例高度使报告完整。正确：缺项明确留空，已有其他字段继续处理。
- 错误：修改统一参数后只更新网页文本。正确：核查该参数影响的表格和导出物；无法同步的成果标明需重生成。
- 错误：精简计算书时省略用户指定的详细目录。正确：目录保留，删除重复解释。

来源规则：R15–R19、R02、R27。本场景不恢复论文研究，也不替代工程专业设计确认。
