# MCP 小节编辑

source_id: USER-MCP-SUBSECTIONS-20261110。按本轮授权实现扩初各章节共用的小节读取、局部改写，复用表格单元格接口；未改地勘提取器或恢复 Office 编辑界面。

## 使用

1. `workbench_expansion_outline` 读取章节、小节 ID。
2. `workbench_expansion_subsection_read` 读取目标小节。
3. `workbench_expansion_subsection_edit` 提交明确项目、单体、当前 `expectedRevisions`、小节 `expectedText` 和新 `text`。
4. 撤销时重新读当前版本，用返回的 `previousText` 作为新文本，再调用小节编辑接口。

编号小节按层级定位，例如 4.2、4.4.1；没有编号小节的章节使用 `body`，章首使用 `intro`。重复编号不选择第一处。保留小节之外的源文本、原换行、参数引用和图表标记；小节编辑不负责增加或重命名标题。父小节改写须保留下级标题。表格值沿用 `workbench_expansion_table`。
