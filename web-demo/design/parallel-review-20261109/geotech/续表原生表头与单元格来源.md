# 续表原生表头与单元格来源

source_id: QA-NATIVE-CONTINUATION-20261110（原页及数据组件验证，原文事实）。

湖北PDF物理第12页提取表20、第13页提取表21为同一承压水腐蚀性评价表的前表与续表。前者含五列表头及六行数据，后者有侵蚀性CO₂和HCO₃两行、无自身表头。原页分别查看确认；原报告PH栏所标单位也保持，不在提取中擅自纠正。

新增 `geotechRetainedNativeTable`，仅沿既有已接受的continuationOf与headerSource关系继承表头。前表必须也通过章节筛选；检查前后方向、列数、表头层数、合并区域边界，以及合成矩阵与既有提取记录一致。关系、数值或几何不符即由章节接口保留文字回退，不猜测匹配。

继承单元格保留sourceCell，记录来源表、行、列；正文数据仍指向续表自己的行列。后续续表若继续继承，表头来源沿链保留。整段仍置于续表原位置，不将前表的数据重复复制到续表。
