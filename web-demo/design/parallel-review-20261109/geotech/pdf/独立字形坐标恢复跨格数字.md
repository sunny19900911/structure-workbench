# 独立字形坐标恢复跨格数字

source_id: QA-PDFIUM-NUMERIC-20261110。原页事实与本地实测；未借用其他版本Word或历史工程参数。

## 发现与修复

信阳PDF物理第13页的数字在渲染图上分列清楚，但pdfplumber读取的部分字符坐标产生连续错位，pypdf文本读取也得到相同连串。此前仅标记跨格冲突并留空；进一步检查发现Pk行最后两格因字符前移而成为未被标记的空格。

本机已有的pypdfium2可读取独立字形坐标。本轮新增 `verify-numeric-rows.py`，只处理已发现数字跨格冲突的单行数值区域：

1. 按原物理单元格获取PDFium完整字形和边界文字，两者必须一致。
2. 每个字形必须在对应格内；跨界、多行、范围值、非数值及不连续单元格拒绝恢复。
3. 整行两种读取的数字字符必须顺序完全一致，不增删字符、不换数字、不补小数点。
4. 同时核验整行，包括此前未标记的空格；保留原格文字、原坐标、冲突记录与恢复记录。

`extract-native-report.py` 显式增加 `--verify-numeric` 开关；未开启时保持原行为。独立引擎缺失时该开关报错，不假称完成复核。横向跨栏合并与实验编排保留恢复依据，并区分已恢复与仍待核的提示。正式工作台上传入口未修改。
