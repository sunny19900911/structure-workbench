# PDF原图Word输出与页眉补漏

source_id: QA-PDF-IMAGE-DOCX-20261110-R106。原报告为曲靖①号地块27页PDF；输出是独立断裂带章节验收样稿，不是正式项目成果。

## 从实际样稿发现并修复

首版Word渲染暴露三项问题：PDF第6页页眉混入正文；“附图1：云南省构造分区图”只有图题无图；活动断裂图被12cm统一限高缩得过小。

1. nativeReportSource在页顶12%范围内识别“共N页第M页”，仅当N与本PDF页数、M与物理页号同时一致时排除，并保留排除证据。正文内相同文字及不匹配页数不删。
2. 地勘图片选择补充“构造分区”图题。原页左侧构造分区图经裁取、目视核验及同页图题绑定，与右侧活动断裂图分别进入断裂带章节。未把图片内容转成工程数值。
3. 专项render-section-document.py对具有原PDF裁框的图片按原物理尺寸排入栏宽和22cm高度上限，不放大超过原图尺寸；其他Word来源图片保持原12cm限高。原图不重绘、不裁内容。

## 实际验收

修订DOCX由Microsoft Word只读转PDF，共2页，逐页目视检查完成：构造图在第1页右栏，活动断裂图在第2页左栏，图例保留、图题紧随且各一次。图大于剩余栏高时整图移到下一栏，留白保留，未为压缩页数缩小图例。文字连续，未见图片越栏或遮挡。

- DOCX内2幅图片与核验裁图字节哈希一致；34个正文块均保留，无漏段。
- 两图尺寸约17.84×21.10cm、17.34×20.41cm，与原PDF裁框的物理大小相符。
- 错入正文的“共27页第6页”已不存在；原表、OCR待复核页清单保持。
- 67项Node检查通过，覆盖新增图题、正确/错误位置及页数的页眉识别，并复跑原地勘规则。

打包render_docx.py因缺少LibreOffice soffice.exe失败，已检查明确错误；使用本项目既有Word COM备用路径后渲染成功。首个备用调用使用正斜线路径被Word拒绝，改用Resolve-Path得到的本机绝对路径后成功；未改安全策略。PDFium用于渲染产出的PDF页图。没有因验证环境缺少LibreOffice而跳过视觉检查。
