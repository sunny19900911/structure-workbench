# 湖北PDF表格上下标与去重修复

source_id：QA-HUBEI-NATIVE-GLYPH-20261109。原件为湖北影院23页PDF及对应Word审核版，隔离证据位于 `goal-round4/`。本轮是两种格式原报告对照，未找到并核验该项目的扩初终稿，不计作终稿一致率。

## 本轮发现与修复

1. 原生PDF读取恢复33个网格片段（含目录、前言、统计附件，非33张有效扩初表）。化学式在表格单元格内发生上下标错行：例如SO4的4被排在电荷之后、CO2的2落到单位之后。
2. `extract-native-report.py` 在每个真实物理单元格中按字符中心坐标筛选，再调用已有 `glyph-lines.py` 恢复上下标。以单元格最大字高作为主体参考，使短化学式也能识别；不跨单元格取字符，不猜化学式。原始 `rawRows` 和每格 `originalText` 同时保留，输出标记 `glyphReflowed`。
3. 真实导出复核发现，第二张腐蚀性表中相同的NH4、OH行被全局去重删除。`geotech-document.js` 现在保留来源表的独立文字记录，普通段落仍沿原去重逻辑；不同水类型的相同测量值不能视为一条事实。

## 样本核对

先按对应表头、逐层编号及原页位置建立映射，后比较单元格。只统一空白、Unicode兼容上下标字形及减号，没有纠正数值或用Word反填PDF。

|对应表|单元格数|修复前一致|修复后一致|

|承载力建议及多种试验取值|120|120|120|
|层波速|52|52|52|

这是选定六张表，包括表头与空格的固定比较集，不是357个独立工程参数，也不是全报告准确率。Word重复表头只比一次，PDF跨页表先按明确续表顺序拼接。

全部33个网格前后字符多重集合比较（同上述字形归一）无增删。信阳15页、海南9页、上虞12页的90个数字单元格复查没有数值变化；无文本扫描页不适用本次字符坐标修复。原始PDF哈希未变。

## 实际输出

经隔离5444实验包导入、保存、刷新、真实导出按钮完成Word输出。重导出后，SO₄²⁻、NH₄⁺、OH⁻、CO₂、HCO₃⁻分别在两种水的表述中保留两次；其中NH₄⁺、OH⁻修复前各只出现一次。实际DOCX的17张表、480个文字块与浏览器导出包比较，无差异或遗漏。

Microsoft Word只读转为17页PDF，查看全部页缩略图；原始第12页及输出腐蚀性页另作放大检查。仍可见长表转段落冗长、表头文字重复、参数表跨页等编排问题；不标为达到扩初终稿质量。
