# 样号、取土深度与负号对应修复

source_id: QA-SAMPLE-IDENTITY-20261110。依据同一信阳PDF原页，不使用不同版本Word或其他项目参数。

## 处理方法

`verify-sample-depth.py` 仅处理明确具有“土样编号”“取土深度”和m单位表头的原生表。样号、深度及其右侧连续测值按独立PDFium字形坐标读取；碰到非数值栏停止，不跨越土样名称等文字。全部区域的原字符必须顺序一致，不能增删字符、猜编号或深度。

同时发现短横线的墨迹框与数字底部不同，并非多行。单行判断改用同一字体框基线；字形不得越出单元格的条件保留。实际跨行、字形越界、字符泄漏到未核验栏仍拒绝。该修改也恢复两栋建筑各一组标高/负埋深，共4格。
