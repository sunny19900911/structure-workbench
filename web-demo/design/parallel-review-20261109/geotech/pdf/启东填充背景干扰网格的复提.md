# 启东填充背景干扰网格的复提

source_id: QA-QIDONG-FILL-BACKGROUNDS-20261110。陈述类型：本机实测事实。

启东PDF第5页腐蚀表原被提取成11行25列。原PDF包含填充但不描边的灰色矩形，背景及文字背后的矩形边缘混入网格，造成额外行列。直接lines_strict无效：该页表格边框也是细长填充矩形，page.lines为空。

实验读取器增加可选 `--ignore-fill-backgrounds`：仅在网格检测时忽略不描边、填充且宽高均超过3点的矩形；保留细长填充线、描边矩形、文字，原文件不改。默认读取行为不变，native-report记录gridRulingMode，不能无条件推广，因为别的PDF可能用填充矩形边缘表达真实单元格。

整份11页重新读取，候选表数57→15，正文段落仍471。腐蚀表恢复9×9并进入整理结果，桩基估算表恢复23行。腐蚀表与Word第7表81格逐格比较：74格忽略空白后一致，另外7格仅为SO₄²⁻、NH₄⁺等上下标表示差异；不把Word扁平字符覆盖PDF原上标。Word/PDF是一审前后版本，其他表值仍需核验，未以表格数下降宣称全表正确。
