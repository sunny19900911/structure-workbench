# 旋转统计表与原页坐标恢复

source_id: QA-ROTATED-LAB-20261110。信阳同一原PDF物理第20页，原件只读，未使用其他项目或Word版本补值。

## 根因与修改

该页全部2811个原生字形旋转90度，旧读取按纸面横纵坐标组织，造成237个数值格待核。仅修改PDF旋转标记不能让两个读取器使用同一文字坐标系。

新增 `page-orientation.py`：至少40个非空字形、98%以上方向一致且为90/270度时，才归一化整页；混合方向、少量侧边标题和正常页面不旋转。通过内存中的单页副本把旋转落实到内容，再读取；原始文件不写入。

旋转内容产生的极小浮点误差曾使竖线被当成横线。本轮仅对偏离坐标轴小于0.001 PDF点的线段恢复轴向，斜线不拉直。恢复后为一张64行31列统计表，包含6个地层及各自10种统计行。

每个表格、段落及单元格保留归一化坐标与 `sourceBBox` 原页坐标；页面记录旋转角及原尺寸。原生字形字符清单旋转前后完全一致。读取器、实验编排、资料保存都保留这些依据。
