# 扫描水质表数字与离子名称分开复核

source_id: QA-WATER-ION-LABELS-20261110-R113。以下为原页目视与本机实验事实。

本轮扩大到莒南报告物理第81页水质检测表。该页不是分层波速图，不能套用分层表的物理行规则。物理第83、85页目视确认属于勘察委托任务书，不作为实测地勘结果。第87页仅生成页图，未作内容核验。

从第81页原始扫描页裁出检测表，使用现有本地PaddleOCR v6 ONNX直接检测和识别，保持检测框分离。144dpi、288dpi两种渲染各独立识别一次，未改像素中的文字、未将参考答案输入识别器。裁图不含签名区域。

|复核对象|144dpi|288dpi|
|---|---:|---:|
|12行×4列及表下4项数值|52/52|52/52|
|10个离子名称，要求保留电荷与数字|5/10|5/10|

五个阳离子名称在仅归一化Unicode上下标字形后吻合。五个阴离子均未通过：Cl⁻被读为CI，SO₄²⁻出现SOd2，HCO₃⁻出现HCO{3，CO₃²⁻缺负号且数字次序表达不明，OH⁻缺负号。加倍渲染未修复这些错误。参考标签只是原页人工核对依据，未写回OCR结果；不做字典猜改或水质腐蚀性判定。

本次将新错误固定为可复跑的验收样本。评分分别保存数字、标签、置信度和原页图坐标，不再用数值正确率代表整表正确率。固定取样位置来自原页表格，各位置要求唯一文字框；既不寻找最佳匹配值，也不把多框静默拼接成答案。
