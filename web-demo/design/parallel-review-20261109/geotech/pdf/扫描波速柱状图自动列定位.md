# 扫描波速柱状图自动列定位

source_id: QA-XINYANG-AUTO-COLUMNS-20261110。

本轮把第25轮人工指定裁切坐标替换为两阶段自动流程。scan-wave-columns.py 先读取整页OCR给出的候选表区域，再用长竖线共同起点定位列表头，排除起点在表头下方的曲线坐标轴；只接受八条边界组成的七列、符合宽曲线区布局的结构。单独放大识别表头，要求序号、地层名称、深度(m)、厚度(m)、柱状图、层速度(m/s)证据成立，才生成数据列图。数字期望值不参与定位或识别。

仍为特定表型的实验处理器：空白图、缺竖线、多个几何候选、缺表头、缺单位、错误单位等保留pending状态。选择结果记录源图哈希、候选框、表头OCR路径、像素裁切框，未自动写入工程参数。

## 实测

|样本|整页OCR正确数值|自动定位数据列后|
|---|---:|---:|
|原5页（121/124/127/130/133），18层|32/54|54/54|
|另选第123页左栏柱状图，4层|9/12|12/12|

原5页除深度/厚度/层速度外，含序号与层名共90字段也全部对应；新页20字段全部对应。第123页未用于几何调试，位于左栏，旁侧是另一钻孔的三列测点数据表；算法选中左侧目标表。该页原PDF包含文本及图像，本轮以180dpi整页图像验证OCR路径，不能称为新增纯扫描项目。未扩展到其他勘察单位或任意表型，不作通用准确率声明。

原5页自动生成的表头图与先行几何实验逐像素一致，复用其OCR结果；自动数据列图均重新OCR，没有复用人工裁切的识别结果。识别前没有读取人工期望数值，结果后对原图核对。CSV的22行来自实际OCR字段，原页码保留。表头局部切分仍可能影响最终OCR，输出列名由核验通过的表头契约提供。

## 验证与限制

新增测试5项通过，覆盖双分辨率坐标轴排除、缺线/空白/非法框拒绝、表头字段单位校验、多表头拒绝；既有扫描网格5项和列带拼接3项通过。6张来源图哈希未变。没有修改生产正文编排，未重跑既有终稿选段测试或重导扩初；此前Word/PDF事实与终稿对照仍保留原记录。

层速度不等于等效剪切波速，层厚不等于规范覆盖层厚度。扫描结果尚未挂入正式PDF导入，也没有将附图细节自动变成扩初采用参数。下步应以其他项目/不同表型扩测，并完成表头、孔号和数据来源的一体化校验，避免把可读扫描图误称为完整工程事实。
