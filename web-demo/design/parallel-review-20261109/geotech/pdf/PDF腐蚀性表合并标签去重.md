# PDF腐蚀性表合并标签去重

source_id: QA-PDF-CORROSION-MERGE-R123（实测事实）。

上虞原PDF第13页表6的三级规范限值行，首两列实际是同一合并格。原生提取正确保留了几何，但正文记录将每个展开槽位输出一次，使规范规定标签各重复一次。目视原页确认后，geotechCorrosionRecords增加可选PDF元数据，仅在相同物理单元格、标签和值相同、无待核标记时消除重复。没有几何或不同条件的相同值均保留；原始表格不变。

实际来源复核消除3处重复标签，全部数字字段保留；两组水样的氯离子干湿交替、长期浸水条件均保留。生成正文链路使用修复结果，原始PDF哈希与R122相同。原页HCO3后的符号位置偏低，未凭化学惯例改写。此次没有发现该表pH/氯离子标签错配，不能将Word上一轮问题套用到此PDF。

72项相关测试通过。证据：web-demo/qa/parallel-review-20261109/geotech/goal-round123/ 的shangyu-corrosion.png、checks.json、generated.txt、tests.log、check.mjs。测试首次写入因重复web-demo路径失败，修正路径后新增两项已实际运行；真实链路断言改为比较来源路径和值，避免把既有标签空白规范化当成数据差异。

本轮属于正文结构保真改善，不是数值识别率提高；未重新验证浏览器或Word导出。尚未接入正式PDF上传，不宣称已完成整体提取目标。
