# 页眉隔离与跨报告复验

source_id: QA-PDF-MARGINS-20261110。新读取方法的页眉此前可能与正文先合并，事后重复段落过滤无法分离。本轮在合并前按原页坐标识别重复小字号边缘行：至少出现于3页，限页面顶/底边缘，字号高度低于正文中位字号；逐项保留剔除文字、页码和矩形坐标。正常字号的重复标题、正文中同名文字及单次页脚不据此删除。

## 实测

- 右江44页：登记并剔除34处页眉。逐页比较旧文字字符与新文字加剔除项，忽略空白后全部守恒，23个原生表片段完全不变。地勘编排表的键和行值也完全一致。实际Word中的该勘察单位页眉字符串由10处降至1处，不能宣称全部页眉已清除。
- 湖北23页：登记17处边缘行，逐页字符守恒，33个表片段不变。
- 海南12页：登记11处页眉。初始字符守恒检查失败，查明旧双栏裁切会把跨栏页眉边界字符重复读取；没有忽略失败。按旧块坐标只分离页眉区域后，12页正文字符全部守恒，12个表片段不变。初始失败及定位后的核对均保留。
- 新海南PDF与正确配对扩初终稿的两条跨块逐字沿用段落仍2/2；Word既有配对检查保持经开30/30、比勒费尔德10/10、云南旅游10/10、海南5/5。不同分母不能合称整体正确率。
