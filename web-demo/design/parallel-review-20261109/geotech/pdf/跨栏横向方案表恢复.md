# 跨栏横向方案表恢复

source_id: QA-XINYANG-HORIZONTAL-20261110。本轮解决列对应与方案保留，未完成全部数字纠错。

## 方法与边界

信阳PDF物理第13页表7.5从左栏底部续到右栏顶部，分别提取为10列和11列。首段缺少文学院合并单元格内部的分隔，不能按数组列号直接拼接。

新增独立实验模块 `horizontal-continuation.mjs`：仅接受同页相邻栏、直接相邻、首段明确建筑名称、续段明确持力层并包含基础形式的横向表；两段宽差须小于3点，首段已有列边界必须能在续段边界中找到匹配。按归一化几何坐标展开合并格，逐个位置必须唯一对应原物理单元格；不根据数值大小或其他格式猜测。不同标题、页码、列几何或中间有段落时不拼接。

两段原始表格、单元格原坐标和原读取文字保存在来源元数据，冲突标记及空值继续保留。实验编排表数量由199片段变为198张组合/独立表，这只是合并结果，不代表附图表全部可用。
