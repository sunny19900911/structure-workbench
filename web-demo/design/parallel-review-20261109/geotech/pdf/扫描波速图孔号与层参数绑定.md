# 扫描波速图孔号与层参数绑定

source_id: QA-SCAN-IDENTITY-20261110。原文事实来自信阳同一PDF物理页121、123、124、127、130、133的图像；方法与局限为实现记录。

此前分区OCR已恢复22层的66个深度、厚度、层速度数值，但单独的层表缺少钻孔身份，不能可靠供给后续资料编排。本轮沿已核验列几何，自动裁取柱状图上方的身份栏，重新运行本地MinerU，再按明确标签读取钻孔编号、孔口高程、终孔深度及等效速度。期望值没有参与OCR。

原图逐项核对24字段全部一致：ZK35、ZK60、ZK67、ZK92、ZK113、ZK163。图示等效速度原文依次357.00、163.70、309.53、356.33、183.32、160.52。身份栏没有明确单位，结构化记录不推断单位；层表的m、m/s来自先前独立核验的列头。层速度与图示等效速度分别存放，不计算覆盖层厚度。

`scan-wave-identity.py` 执行prepare→本地OCR→read，检查来源图哈希；`bind-scan-wave.py` 将相同图像哈希和页名下的身份与实际OCR层表绑定，保留两套OCR证据、表头证据、裁切框及页码。遇到多表、序号不连续、数值粘连或身份冲突时拒绝绑定。新增8项测试通过；实际5张纯扫描页18层和另选混合页4层均绑定成功，来源图不修改。

QA `goal-round35/` 保存身份图像、OCR原文、24字段图像核对、6图绑定结果及22行CSV。本轮改动仅在实验工具，不修改生产编排；未做浏览器上传、Word导出或终稿完整性复验。该结果只覆盖目标柱状图，不代表整页其他曲线和测点表已读取完整。正式PDF入口及自动编入资料尚未完成；这些结果也不是设计采用参数。
