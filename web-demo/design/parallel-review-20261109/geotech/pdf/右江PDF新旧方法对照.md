# 右江 PDF 新旧方法对照

source_id: QA-YOUJIANG-PDF-20261110。以下是本轮实测事实，不代表全报告准确率。

## 样本身份

PDF 为右江民族医学院百东校区一期详勘，2017年，广西地矿建设集团有限公司；同目录 Word 为2019年图书馆详勘，百色市综合规划设计院。两者不是同版本，未互作准确率基准，也没有对应的已核实扩初终稿。本轮以 PDF 原页为依据，新旧读取器处理同一文件。

## 新旧结果

44页中43页有文本层，1页无文本层待复核。旧坐标行读取器恢复0张表，新方法按单元格边界和字形坐标恢复23个表格片段。这是结构恢复数量，不是23张表全部正确的证明。

对物理第30页表5-2逐项目视核对：8栋建筑的波速、覆盖层厚度和类别24项一致。发现“计算钻孔”表头未映射钻孔编号，已在地勘专属适配器补识别；实际导出Word的8个钻孔编号及24项参数共32项均与原页一致。保留建筑物名称和钻孔的对应关系，未从波速推算场地土类型。

独立Word样本另修复横向钻孔参数表：2个孔的波速、类别进入场地表，计算深度仍按原字段保留，不冒充覆盖层厚度。其结果不计入PDF准确率。

## 验证与范围

- 69项相关Node测试通过，构建通过（原有分包警告保留）。
- PDF实验成果包在5444隔离页面导入、保存、刷新、下载成功，原件哈希不变。实际DOCX的17张表、217个文本块与导出包一致，Word渲染9页，已查看场地表所在页。
- 独立Word样本实际上传、保存、刷新和导出通过，17张表、143个文本块无差异；未做本轮整份Word分页目视验收。
- 数据在 `qa/parallel-review-20261109/geotech/goal-round13/`；PDF原页、旧读取结果、原生读取结果、逐项校核、实际导出及渲染均保留。
- PDF仍经实验成果包导入，未接入正式PDF上传入口；未修改共享入口和正式项目库。
- 表格仍重复转成长段文字，个别页眉混入正文，物理参数固定表仍有空项；无文本页尚未OCR。当前成果是复核稿，不是完整终稿。
