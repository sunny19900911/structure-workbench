# PDF不同土层重复续句补漏

source_id: QA-QUJING-LAYER-TAIL-20261110-R85。陈述类型：本机实测事实。

扩大曲靖①号地块终稿对照到岩土评价、水文和相关地质结论，选定50条不少于20字的短句。原Word中41条可逐字定位，原PDF中34条可逐字定位；未定位不直接算提取错误。改前分别保留36条和27条。共同缺少的5条是气象章节被规则主动排除，本轮暂未改；PDF另漏第③、④层土的末行适用条件。

原因：`uniqueGeotechProse`已按完整句段去重，但`geotech-document.js`的compact又按单行去重。第②、③、④层均有相同结尾“稍具不均匀性，分布较厚地段经地基处理后可作天然地基土使用。”，后两层的限定条件因此丢失。修复：经章节解析的正文不再逐行去重，仍由完整句段去重负责；旧关键词回退路径不变，表格记录继续保留。

验证：

- 新增`repeated-layer-tail.test.mjs`两例，覆盖不同层相同续句保留及完整重复句仍只出现一次；连同regression和section-blocks共67项通过。
- 同一固定短句集复查：Word仍36/41，PDF由27/34到29/34；恢复终稿146、147段，保留各自OCR固结比15.17和5.22及后续条件。这不是全文准确率。
- 隔离工作台5444实验导入，项目a429aabf9fcb4f95a2422f6ee36b6677，导出17表603文本块，与页面文档包比较差异0、漏文本0；恢复的两条完整短句都在DOCX内。刷新后项目/来源哈希一致，原件哈希不变。
- 未渲染导出Word分页；实验导入不等于正式PDF上传入口已接入。第6页OCR待审状态仍保留。

证据位于`web-demo/qa/parallel-review-20261109/geotech/goal-round85/`，包含改前、改后短句清单、实验包、实际页面导出、文本/表格验证及export-clauses.json。后续需处理气象水文覆盖，同时避免把勘察任务、方法或标准背景收进工程结论。
