# 软件演示制作与验收

仅用于软件演示录屏、旁白字幕及成片质量检查。内容取舍与语义断句沿用 [reports.md](reports.md)，这里不重复。用户选定的录制工具、音色和参考样片保持有效；本规则不授权上传素材、修改安全策略或操控其他任务的桌面。

## 原话、字幕和配音

- 先查是否有字幕轨，再查画面是否烧录口述字幕。界面OCR只能辅助核对字段，不能当作用户说过的话。无口述字幕时从原音转写，保留原始ASR及来源时间；专名、数字、轻声词出现歧义时保留待听辨项。
- 可用稿与待复核句分开。问题条目数可能与待复核句数不同，应按实际数据分别统计。不要把画面上未说出的信息补成原话，也不要用一次更差的局部识别覆盖清楚原文。
- 字幕排版行、字幕条目、ASR分段与配音语义分句分别管理。给TTS的是完整语义句；原片等待时长不直接转成配音停顿，不要求声音填满原片区间。
- 有真实合成处理记录时，用保留区间减去已剪静音，再累加已知语义间隔重建短句字幕，并核对整句实测总时长；缺少可靠短句边界时保留句级字幕，不按字数伪造精确对齐。
- 词中停顿先核对模型实际分块；只有一个块时不能断言是自动分块。ASR字时间跨得长可能含静音，不能直接等比压短该字。
- 必须修剪时，结合实测能量、波形与试听确认静音边界，保留发声音节和首尾字；阈值按素材确定。保留原片段和切点记录，检查漏字、重复、接缝、削波及完整解码。机器检查与实际试听分别报告，短样获认可不代表全片通过。

## 标注与视频证据

- 字段和值优先用不遮字的轮廓强调。滚动、导航、填值等会引起页面重排的操作前清除旧框；页面稳定后重新读取目标矩形，光标移到空白处，再展示结果。固定视口坐标不能沿用到重排后的页面，源字段和联动结果都要可读。
- 检查最终编码视频中的标注位置、光标和数值，网页截图只证明当时页面状态。
- 字幕与结果放大区避免重叠，可采用独立字幕区域。局部裁切绑定同一来源及稳定时间区间的真实帧，滚动前后重新核对矩形，不能用另一时刻的截图坐标覆盖当前镜头；以实际编码抽帧确认可读性。
- 点击光圈以真实输入事件为依据。补录没有pointerdown等可核实点击事件时，不从红框、填值或画面变化反推出点击时间和位置；保留可验证的强调框与画面，不合成虚假的点击证据。
- 低平均帧率或长静帧本身不能证明冻结。把操作事件时间与实际解码PTS对齐，核对预期变化及相邻帧；无对应事件的动作不报告精确响应延迟。采样间隔要写进结论限制。
- 转成30fps时复制静态帧不等于补回动作；缺失操作应补录。解码成功、抽帧通过、实时播放和完整内容验收分别报告。
- iframe内语义点击可能受父页固定栏遮挡。动作返回成功后仍核对实际新文件或明确业务结果；失败时先看当前画面和遮挡，再使用当前工具允许的可见目标定位，不重用旧坐标或连点猜测。
- 原生Office文件、网页基础预览和Office应用渲染分别核验。先区分源数据重复/缺失、表头分页标记错误与预览布局未实现；只做XML或隔离文件修复时保留视觉待验和未应用到运行包的状态。
- 局部缺陷消失但其他视觉错误仍在时，分别更新状态。达到任务约定的修复轮次上限后保留未解决结论与失败证据；文件哈希、ZIP检查或原生顺序通过不能覆盖分页错序事实。

## 中断和任务交接

- 给录制辅助增加控制入口时，可用独立端口和不共享/不开录的回执模式验收，保留既有录屏会话。依次区分纯逻辑、真实小窗操作、真人物理键收信和授权后的媒体输出；按键回执成功不证明暂停续录成片、麦克风听感或窗口未入画。独立入口不能偷偷开录，真实采集仍遵守原授权。

- 本地转码、混音和全解码可能正常耗时较长。结合进程可轮询、输出进度和持续生成的文件判断；仅超时阈值信号保留待核，不能直接称卡死。耗时信号与同时发现的具体代码缺陷分开登记。
- 接续长任务前核对现有worker身份、CPU增量、产物更新和退出状态；CPU占用本身不证明有效进度。健康进程继续复用，避免重复启动消耗资源；产物存在也不等于成功退出或验收。

以下检查来自失败复盘，预防效果须随下一次实际流程验证。

- 控制中断先暂停并保存已有录制，核实saved及产物后继续；若保存超时先查状态和文件，不盲目重放。调查连接状态和错误证据，不先认定CPU或安全策略是原因。恢复控制后重新核对录制源，等待不进入正片。
- 切换单体或对象后先观察当前导入按钮，已有/未有资料可能对应不同状态。工具支持文件选择事件等待时，按当前文档先注册等待并立即附异常处理，再点击，使用合理有限超时；把拒绝转为明确失败，不留未处理Promise，也不吞掉错误冒充导入成功。恢复后分别确认控制连接、共享源和业务结果。
- 观察器查询失败、浏览器调试连接失效与Socket.IO断连分别核对。旧代码可能合并错误标签；历史日志不足时保留未知原因，修复诊断代码也不能倒推历史故障。原片saved、哈希一致、恢复后持续录制、诊断补丁部署和整片验收是不同状态。
- 跨回合仍需录屏页和目标页时，按当前CUA文档分别保留两页。工具提供turn-scoped markHandoff时，在相关回合执行并核对交接；下一回合再确认页面存活、控制连接与源身份。不能把页面保留视为共享授权永久有效，也不能因漏保留造成用户重复授权后将它算作必要操作。此检查来自失败复盘，实际跨回合效果另行验证。
- 多任务接续时明确当前产物、负责人、下游动作和完成标准。在已有用户授权内派发并核对接收/运行情况；没有授权时不因本文件自动发送消息。active仅说明在运行，idle或“已同步”也不表示整片完成。专项结束后核对文件并接续下游，直至约定成片或明确人工阻塞。

## 媒体组装的路径与时间轴

- CLI允许相对输出目录而子进程会切换cwd时，在入口按调用方工作目录解析绝对路径，再派生滤镜文件和输出文件；不要让同一路径随子进程cwd被再次解释。
- 对稀疏帧录屏，按原时间轴重采样后裁剪，并核对裁剪时长和实际解码结果；不要将重复帧说成补回动作。补录使用明确的源步骤名和片段来源，不二次减时间偏移，也不补造点击事件。
- 静音补录拼接成功仅支持局部媒体流程；全片音频、字幕同步、听审和完整回放仍各自验收。
- 长合成开始时记录输入签名，合成后交付前再次核对最新输入。发生音频或文稿更新时保留旧产物，拒绝旧版本完成声明；只复用签名未变且文件哈希正确的镜头，按变化内容的实测时长重排、合成和复验。不要只在开始前检查版本。
- 上游持续修订时，可交付与音频、文稿和剪辑输入快照绑定的候选版，明确版本和待听审时间定位。核对快照确实匹配渲染输入，分别记录解码、字幕章节完整性、抽帧、完整播放和人工听审；候选通过技术检查不能自动升级为最终验收。
- 多段已统一帧率的有声视频，按实际帧数裁齐各段音画，以帧数/帧率累计字幕和章节起点，避免容器尾部时长误差积累。核对输出帧数、总时长和段界同步；不要把某次30fps设为所有项目的固定参数。
