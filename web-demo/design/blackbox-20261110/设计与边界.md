# 小黑箱本机管理窗口

source_id: USER-BLACKBOX-20261110；实现判断为 AI 推断，验证另见验收记录。

主屏以 concept.png 为参考：白底、深灰文字、蓝色主操作；黑色方块标记、26px 标题、22px 状态、18px 分区标题、14px 控件。内容顺序为运行状态、当前项目、打开工作台、AI 连接、成果/目录、退出后台。原生窗口按钮交给 Edge 应用窗口，不在网页假造。

主屏文案来自用户范围和概念图。必要状态增量：页面未连接/执行中、真实 MCP 心跳、源码变化。设置弹窗只含目录选择、输出位置说明、版本及保存；连接弹窗只含配置、复制和客户端重连说明。无新增工程确认卡片，无 Office 网页编辑器。

关闭管理窗口不退出后台；关闭业务页不退出后台，但组稿操作不可用。退出后台只针对当前服务实例，拒绝有任务、存活页面或其他未完成请求的情况。不调用 taskkill，不根据端口或 PID 杀进程。页面最后心跳可能保留两分钟，窗口明确提示等待释放。

目录关联沿用原项目库与 expectedRevision，仅创建空项目身份和 folder-binding。规范化目录散列作为稳定 ID；输入目录原件只读。成果存项目目录/工作台成果/批次，写入使用 wx，重试也不覆盖原成果。扫描不进入成果目录或链接，不自动导入。未绑定目录的旧项目沿用原导出路径。

版本包含 release、源码指纹、实际工具清单摘要；标签一致不代表实现一致。旧服务不自动重启，客户端重连才能发现新工具，不承诺热更新。

豆包：2026-11-10 核对官方应用插件文档 https://open.doubao.com/apps-plugin/docs/release/package-and-submit 。该渠道明确要求公网 Remote MCP，不接受 localhost/stdio。此证据只适用于应用插件发布渠道，不能据此断言桌面客户端全部无能力；当前本项目的本地 STDIO 接入尚未验证，显示待核实，不提供假按钮。
