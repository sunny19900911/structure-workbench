# 线上三项问题修复与验收

来源：USER-20261014-DEPLOYMENT-FIXES（用户要求，原文事实）。

## 原因和处理

1. 抗震等级原来每次修改都先禁用整组控件，复制大份 intake，重建导入资料 DOM，并等待完整分区上传。本轮改为小份条件读取、本地计算、连续输入合并保存；既有修订冲突保护、历史和项目隔离保留。切换项目时等待保存，并再次保存可能被分区更新的主版本。
2. 顶部助理遮罩拦截正文点击；无有效选段时改写只有短暂提示。现在点击正文可直接转入改写，两个侧栏互斥，未选段时打开本章第一段普通文字。仍由用户输入要求后发送，完成后采用。请求流增加心跳，明确报告登录过期和代理超时。
3. 大部分原生表处于 contenteditable=false 区域，只有单体表能编辑。现给原生单元格独立编辑入口，人工值以稳定行身份存于 tableEdits；刷新和导出均使用同一份值。地方规范文字仍修改共享记录，不复制成独立规范库。蓝色加粗表示措施联动；人工格取消该标色，保留未编辑格联动。
4. 原模板使用 pile_safety，而统一措施只有 pile。本轮依据用户“桩基安全等级等于桩基设计等级”的明确要求补字段别名；并补耐火等级的 fire 映射。不是新增结构规范判断。
