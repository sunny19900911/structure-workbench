# 结构工作台 · 产品需求

最后核对：2026-11-14。本文件记录已确定的要求，不把计划等同于已实现；完成情况见[进度与验收](03-进度与验收.md)。

## 交付与操作

同事完整解压一个 Windows 本地包，可以直接使用网页，也可以连接 WorkBuddy MCP。项目各自保存在本机，AI可联网。网页和MCP共用项目、统一参数与生成逻辑；不要求同事部署网站或配置云数据库。

主流程为 **建立项目 → 导入资料 → 填写统一措施及地方规范 → 生成成果 → 人工检查 → 局部修改并重新导出**。

| 功能 | 用户操作与结果 | 必须保留 | 验收动作 |
|---|---|---|---|
| 项目 | 建立独立项目，保存后重开可继续 | 其他项目、原始输入及人工修改 | 两项目往返切换，核对来源及成果 |
| 建筑资料 | 导入说明，提取地点、功能、单体、面积、层数及分口径高度，直接编入扩初 | 来源、单体边界；缺项留空 | 逐项对照原文，不借用历史项目数值 |
| 地勘资料 | 支持不同单位写法及DOC/DOCX/PDF，提取地层、水文、性质评价和基础建议 | 章节、表头、单位、地层编号及不同部位条件 | 每轮3个可用项目，Word/PDF分别看缺漏；未读项目用于复用检查 |
| 模型 | 同批导入WMASS.OUT、WDISP.OUT、WZQ.OUT，保存后计算书复用 | 单体、模型版本和工况 | 对照源文周期、平动X+Y、扭转、位移比及所在层、抗倾覆等 |
| 统一技术措施 | 在网页填写和修改核心参数、荷载、材料等 | 未修改参数和人工正文 | 修改2～3项，比较保存值及Word/PPT适用位置 |
| 地方规范 | 在专页选择、编辑并与扩初协同 | 项目适用范围和版本来源 | 网页与导出一致；不提供已知失效链接 |
| 扩初Word | 按已认可模板组稿，章节可编辑，支持MCP指定小节修改 | 模板表格、图片、相邻节及人工稿 | 原生Word打开，内容与输入对照，检查修改范围 |
| 汇报PPT | 图片集中上传，按专业、图意和楼层匹配，按约定顺序一页一图 | 已人工绑定图片、图题和其他单体 | 批量导入、保存重开、导出逐页核对；歧义不得错配 |
| 用钢量Excel | 导入对应材料文件，输出用钢量统计 | 单位、统计范围、面积口径、基础与上部区分 | Excel可打开，数值/公式与源文件一致 |
| 计算书 | 使用指定封面，复用OUT，扫描盈建科相关PDF并合并 | 原PDF尺寸及内容、项目对应关系 | 实际路径读取、封面视觉比较、合并PDF播放/翻页 |
| MCP局部处理 | 读取明确项目后按指令修改参数或章节、保存并导出 | 其他参数、章节、图表及其他项目 | 通过真实WorkBuddy客户端执行，读取与生成结果复核 |

## 关键内容口径

- 建筑说明提供建筑事实；地勘提供场地事实与建议；OUT提供实际计算结果；统一措施提供当前采用参数。历史样板只提供写法、结构和检查要求。
- 表1可编辑、可删行；无法提取的字段留空。来源颜色仅用于网页，人工修改与自动提取应能区分。
- 参数联动包括地震作用、荷载、构件强度、单体高度与抗震等级；单体抗震等级遵循已有适用范围，不把简单高度阈值当作所有建筑的通用规则。
- 平动系数按`(X向 + Y向)`显示；偶然偏心位移比保留所在层；双向地震按用户指定X向与X向双向工况取值，不能混用其他角度或偶然偏心工况。
- 计算书封面按用户指定QS-324母件及后续单栏、靠左要求；历史人名、签名、注册章不进入当前成果。
- 默认仅输出用钢量Excel，其他Excel批量输出暂停。网页不增加候选理由、重复确认、无效按钮或内部状态卡片。
