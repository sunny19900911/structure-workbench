小香金猪的结构工作台 · 本地版

第一次使用
1. 将压缩包完整解压到自己的电脑（Windows 10/11，64位）。
2. 双击“启动工作台.vbs”；若系统不允许 VBS，可双击“启动工作台.cmd”。
3. 浏览器打开后，新建自己的项目，导入建筑、地勘及模型资料。

不需要安装 Node、Python，不需要宝塔、域名或云数据库。
基础功能不联网。AI 改写为可选项，在“本机设置”填写自己的 DeepSeek API Key 后使用。
AI 只在主动调用时发送相应内容到 DeepSeek；不要把 API Key 发给同事。

数据在哪里
当前 Windows 用户的 %LOCALAPPDATA%\StructureWorkbench。
在本机设置中点击“打开数据目录”可直接查看。
项目与程序分开保存。更新软件不覆盖项目；删除软件文件夹也不会删除项目。
另一台电脑、另一位 Windows 用户的数据独立，项目不会自动同步。
交接时用“导出项目包”，在对方工作台点“导入项目包”，不要只复制网页或恢复备份 JSON。
图片、计算书 PDF 以及实际能找到的已引用 Excel 母件随项目包传递；缺失附件会明确提示。

文件兼容
文件格式与软件版本分别检测；可在本机设置中检查文件。
支持文件类型以检查结果为准。加密、损坏、后缀不符、仅部分可读时会提示，不能将其当成完整识别。
旧 DOC 兼容转换和精确 Word 分页预览需要本机可用的 Microsoft Word。
无 Word 仍可编辑和导出 DOCX、PPTX、用钢量及计算书 PDF；导出的 Office 文件可在自己的办公软件中打开。
扫描 PDF 的 OCR 文字需对照原页，特别是小数点、负号、上下标和表格列。
软件只整理、联动和输出项目资料，不代替结构设计复核；不自动填充无法取得的设计值。

遇到问题
先看页面错误提示；“本机设置”可查看组件、文件格式与实际安装的软件版本。
页面打不开：再次双击启动器；仍失败查看数据目录中的“启动错误.log”。
更新提示已有旧版本运行：先保存内容、重启电脑，再启动新版。
若本机设置文件损坏：先保存 preferences.json 的副本，再重命名该文件后启动。
项目目录不要手工删除；换电脑前导出项目包并保留原电脑备份。

WorkBuddy / Kimi Code / Codex 调用
双击“生成MCP配置.cmd”，按自动打开文件夹中的“先看这里”添加本机连接。
WorkBuddy 使用 WorkBuddy-MCP.json，Kimi Code 使用 Kimi-MCP.json；新增后重连或新建会话。
完整步骤见“MCP连接与使用.md”。结构设计 Skill 在“MCP结构设计Skill”文件夹。
MCP与网页使用同一份本机项目；扩初/PPT等编排功能需要保持网页打开。
本地存储不代表AI模型离线：使用联网模型时，工具返回的资料会进入调用方会话。
