# Linux 宝塔个人试用包

这是带后端的 Node.js 工作台，不能只当静态网页上传。包内是当前工作区版本，包含已完成但尚未提交的页面改动，不包含本机项目库、密钥或 node_modules。

## 1. 上传与依赖

推荐 Ubuntu 22.04/24.04 或 Debian 12，使用独立域名或子域名。把压缩包上传至 `/www/wwwroot` 并解压为 `/www/wwwroot/structure-workbench`。

宝塔安装 Node.js 22.12 或更高版本、Nginx，给站点申请并启用 HTTPS。宝塔终端需能运行同一版本的 node/npm。

Ubuntu/Debian 在服务器终端安装依赖：

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv libreoffice-writer poppler-utils antiword fonts-noto-cjk
npm install -g pnpm@10
cd /www/wwwroot/structure-workbench
bash deploy/baota/install.sh
```

其他Linux发行版请安装对应软件包后执行安装脚本。首次安装需要服务器联网下载 Node/Python 依赖，安装失败应停下检查错误，不要跳过。

## 2. 配置与启动

编辑根目录 `.env`：自行填写 `WORKBENCH_USER`、至少16位的 `WORKBENCH_PASSWORD`。DeepSeek 密钥可留空，留空时AI功能不可用，其余功能仍可试用。不要把密钥发到聊天或放入前端。

若解压目录不是上述目录，同时修改两个 Python 路径。给运行用户读写 `/www/workbench-data`、程序内 `outputs` 和 `.tmp` 目录的权限。项目数据放在网站目录外，升级时不覆盖。

宝塔「网站 → Node项目」添加项目：

- 项目目录：`/www/wwwroot/structure-workbench`
- Node版本：22.12或更高
- 启动文件：`deploy/baota/start.mjs`，或用命令 `npm start`
- 端口：5190，监听地址固定为127.0.0.1
- 开启进程守护与开机启动

在域名站点配置反向代理到 `http://127.0.0.1:5190`，发送域名保留原始Host，参数参考同目录 `nginx-location.conf`。入口部署在域名根路径，不放在 `/workbench/` 子路径。不要对外开放5190端口，也不要把程序源码目录作为静态网站直接发布。

打开 `https://你的域名/`，浏览器提示输入上述用户名和密码。没有配置账号密码，程序会拒绝启动。这里是个人试用入口，不含多人账号和项目权限隔离。

## 3. 原项目与本地资料

- 新建空白项目后上传建筑、地勘、OUT和图片。
- 个人试用建议先新建项目。现有页面提供下载项目备份，但没有通用备份导入按钮，本包不自动迁移旧项目库；请不要用旧备份直接覆盖服务器数据文件。
- 服务器无法访问电脑的E盘。计算书PDF要先放到服务器目录，再在页面输入服务器路径，维持“荷载校核/计算书/上部/基础/施工图”的原目录结构。
- `CALCBOOK_SOURCE_DIR` 指向计算书母件/Excel文件目录，未上传母件时相关Excel和母件功能不可用。
- 腾讯ima、本地602方法库和108经验库没有随包迁移，需要另外配置服务器路径/接口。本包不携带这些资料或密钥。

## 4. Linux试用边界

- 项目保存、网页编辑、前端PPT和CSV输出沿用原功能。
- DOCX读取由Python完成。旧DOC通过LibreOffice转换，少数非标准DOC可能仍需在电脑另存DOCX。
- 扩初原生Word继续使用现有表格模板。其他说明采用LibreOffice转换并设置A3双栏；PDF/预览也由LibreOffice生成。
- Linux中文字体和LibreOffice的分页可能与Microsoft Word不同，不承诺与本机Word版式完全一致。正式文件请下载后在Word核对表格、图片和分页。
- 后端有数据修订冲突保护，但不是全院多人正式部署版。

## 5. 首次验收与备份

1. 未登录访问首页/API，应要求登录。
2. 新建测试项目、上传一份DOCX，检查提取结果。
3. 修改参数并保存，刷新页面确认数据仍在。
4. 试一次Word、PDF预览和PPT导出。
5. 重启Node项目，再确认保存的项目可打开。

定期备份 `/www/workbench-data` 和服务器 `.env`，备份放私有目录。升级前停止Node进程，保留 `.env`、数据目录和自有母件，替换程序后重新安装依赖并启动。

打包机为Windows，已做接口和静态资源检查；Linux上LibreOffice、字体及实际宝塔部署仍需按上述步骤验收。本包不会自动上传、部署或开放公网。
