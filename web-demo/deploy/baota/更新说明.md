## 本次修复

- 每次打开选段默认关闭“联网补查依据”和“深度思考”。普通分条、精简、润色直接调用 DeepSeek；需要查资料、分析时仍可主动勾选。
- 普通文字修改减少无关上下文。正文完整返回后立即显示完成，不再等接口关闭连接；失败、停止有明确回复，避免重复发送后只剩用户气泡。采用才替换原文。
- 删除取消强制下载整个项目。先保存当前修改，再将项目标记为删除；服务器原资料和历史版本保留，可用“恢复刚删除项目”恢复。需要额外副本时仍可主动“下载项目备份”。保存断线或冲突时中止删除，保留当前稿。
- 打开旧项目不再提前下载其他单体的完整扩初稿和图片，不再重复扫描项目清单。已有重难点判断只读取所需参数、模型和规范；完整文稿在打开 PPT 时读取。
- 建筑、地勘提取结果在同一资料版本内复用，原文展开时才显示。替换资料、移除资料或切换项目后重新提取，正文、联动及原始资料仍保留。
- 包含此前高度回车联动、直接选段 DeepSeek 改写、扩初表格编辑和蓝色加粗联动修复。

## 上传及安装

本包只更新程序。保留原 `.env`、账号、DeepSeek 配置、项目库、依赖和导出文件；不更改 Nginx、主站或其他网站。仍用原登录账号。

1. 宝塔文件管理打开已有目录 `/www/workbench-fix-20261015`，把 `structure-workbench-work-rewrite-20261015.zip` 上传进去。本次不用新建目录，也不要在目录名称框输入终端命令。
2. 打开宝塔终端，粘贴下面这一段。使用 Python 解压，避免宝塔解压中文文件名导致清单校验失败。

```bash
(
set -e
cd /www/workbench-fix-20261015
python3 -m zipfile -e structure-workbench-work-rewrite-20261015.zip rewrite-unpacked
python3 rewrite-unpacked/UPDATE.py /www/wwwroot/structure-workbench
)
```

看到“待更新程序文件”且没有报错后，执行下面这一段（只短暂停止工作台）：

```bash
(
set -e
systemctl stop structure-workbench.service
trap 'systemctl start structure-workbench.service' EXIT
python3 /www/workbench-fix-20261015/rewrite-unpacked/UPDATE.py /www/wwwroot/structure-workbench --apply
)
systemctl is-active structure-workbench.service
```

这次没有新增第三方依赖；上次已成功安装的服务器无需重复安装。脚本自动校验、备份程序；更新失败会尝试还原本次已替换文件。终端打印的备份目录请保留。

3. 显示 `active` 后，打开 https://smarter-xuan.xyz/work/ ，按 **Ctrl+F5**。
4. 可打开 https://smarter-xuan.xyz/work/workbench-version.json 检查是否显示 `structure-workbench-work-rewrite-20261015`，确认实际运行的是本包。
