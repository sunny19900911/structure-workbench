# 计算书修复包

适用：https://smarter-xuan.xyz/work/ 。保留原项目、账号、DeepSeek配置及主站。本包包含主工作区此前的更新。

## 更新

1. 上传 `structure-workbench-work-calculation-20261015.zip` 到宝塔已有目录 `/www/workbench-fix-20261015`。
2. 宝塔终端执行下面一段。先检查PDF工具、解压及校验，再短暂停止工作台更新；程序有备份，退出时自动启动服务。

```bash
(
set -e
cd /www/workbench-fix-20261015
command -v pdfunite >/dev/null || { echo '缺少 pdfunite，请先执行 apt-get update && apt-get install -y poppler-utils'; exit 1; }
python3 -m zipfile -e structure-workbench-work-calculation-20261015.zip calculation-unpacked
python3 calculation-unpacked/UPDATE.py /www/wwwroot/structure-workbench
systemctl stop structure-workbench.service
trap 'systemctl start structure-workbench.service' EXIT
python3 calculation-unpacked/UPDATE.py /www/wwwroot/structure-workbench --apply
)
systemctl is-active structure-workbench.service
```

3. 显示 `active` 后，网页按 Ctrl+F5。检查 `/work/workbench-version.json` 中版本为 `structure-workbench-work-calculation-20261015`。

## 使用

- 计算书 → **选择本机文件夹** → 选择盈建科输出目录。只上传荷载校核、上部、基础、施工图中的PDF。
- 清单出现后可预览、下载原件；点击 **合并导出 PDF**，按上述分组和文件名顺序输出一份PDF，保持原页尺寸。
- 输入框仅供读取服务所在电脑的路径。在线网站不能直接读取访问者的 `E:\…`，应使用文件夹选择按钮。
- 原有 **一键生成 A3 Word** 仍用于封面、当前目录、OUT及已配置Excel。未勾选人工确认会给出提示，不再无反应。生成稿去除母版历史签章图片。

单份PDF上传64MB内、一次200份内、总计512MB内。服务器的 `/work/` 代理应保留已有 `client_max_body_size 80m` 和300秒超时设置；遇413时检查该项。PDF合并使用Poppler的pdfunite，不需要新增Python依赖。

PDF副本默认在 `WORKBENCH_DATABASE_ROOT/calculation-uploads`，与projects项目目录一并备份；本次更新不会清除旧批次。若提示写入失败，请检查运行服务的用户是否有该目录的写权限。

本机已完成真实上传、预览、合并下载、页序及尺寸校验和Word生成；尚未在你的Linux服务器实测。更新后请用一个小目录先试一次。
